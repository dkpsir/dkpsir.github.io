Given: \(L = 8\text{ m}\), \(W_1 = 64\text{ kN}\) at \(x_1 = 1\text{ m}\), \(W_2 = 48\text{ kN}\) at \(x_2 = 4\text{ m}\), \(E = 210\text{ GPa} = 210 \times 10^6\text{ kN/m}^2\), \(I = 180 \times 10^6\text{ mm}^4 = 1.8 \times 10^{-4}\text{ m}^4\).

1. Flexural Rigidity (\(EI\))
\[EI = (210 \times 10^6) \times (1.8 \times 10^{-4}) = 37{,}800\text{ kN}\cdot\text{m}^2\]
2. Support Reactions

Taking moments about left support \(A\):

\[\begin{aligned} R_B \times 8 &= (64 \times 1) + (48 \times 4) = 64 + 192 = 256\\ R_B &= \mathbf{32\text{ kN}}\\ R_A &= 64 + 48 - 32 = \mathbf{80\text{ kN}} \end{aligned}\]
3. Macaulay's Deflection Equation
\[EI \frac{d^2y}{dx^2} = -80x + 64\langle x - 1\rangle + 48\langle x - 4\rangle\]
\[EI \, y = -\frac{40}{3}x^3 + C_1 x + C_2 + \frac{32}{3}\langle x - 1\rangle^3 + 8\langle x - 4\rangle^3\]

Applying boundary conditions (\(y=0\) at \(x=0\) and \(x=8\text{ m}\)):

\[C_2 = 0, \quad C_1 = 332\text{ kN}\cdot\text{m}^2\]
4. Deflection Under Each Load

Under \(64\text{ kN}\) load (\(x = 1\text{ m}\)):

\[EI \, y_1 = -\frac{40}{3}(1)^3 + 332(1) = 318.667 \implies y_1 = \frac{318.667}{37800} = \mathbf{8.43\text{ mm}}\]

Under \(48\text{ kN}\) load (\(x = 4\text{ m}\)):

\[EI \, y_2 = -\frac{40}{3}(4)^3 + 332(4) - \frac{32}{3}(3)^3 = 762.667 \implies y_2 = \frac{762.667}{37800} = \mathbf{20.18\text{ mm}}\]
5. Maximum Deflection

Setting slope \(\frac{dy}{dx} = 0\) between \(x = 1\text{ m}\) and \(x = 4\text{ m}\):

\[-40x^2 + 332 + 32(x - 1)^2 = 0 \implies 2x^2 + 16x - 91 = 0 \implies x = \mathbf{3.842\text{ m}}\]
\[y_{\max} = \frac{764.37}{37800} = \mathbf{20.22\text{ mm}}\]
Reactions: \(R_A = 80\text{ kN}\), \(R_B = 32\text{ kN}\). Deflections: \(y_1 = 8.43\text{ mm}\), \(y_2 = 20.18\text{ mm}\), \(y_{\max} = 20.22\text{ mm}\) at \(3.84\text{ m}\) from left end.

Given: \(L = 6\text{ m}\), \(W_1 = 48\text{ kN}\) at \(x_1 = 1\text{ m}\), \(W_2 = 40\text{ kN}\) at \(x_2 = 3\text{ m}\), \(E = 2 \times 10^5\text{ N/mm}^2 = 2 \times 10^8\text{ kN/m}^2\), \(I = 85 \times 10^{-6}\text{ m}^4\).

1. Flexural Rigidity (\(EI\)) and Reactions
\[EI = (2 \times 10^8) \times (85 \times 10^{-6}) = 17{,}000\text{ kN}\cdot\text{m}^2\]
\[R_B = \frac{(48 \times 1) + (40 \times 3)}{6} = \mathbf{28\text{ kN}}, \quad R_A = 48 + 40 - 28 = \mathbf{60\text{ kN}}\]
2. Deflection Equation (Macaulay's Method)
\[EI \, y = -10x^3 + 163.333x + 8\langle x - 1\rangle^3 + \frac{20}{3}\langle x - 3\rangle^3\]
3. Deflections

Under \(48\text{ kN}\) load (\(x = 1\text{ m}\)):

\[EI \, y_1 = -10(1)^3 + 163.333(1) = 153.333 \implies y_1 = \frac{153.333}{17000} = \mathbf{9.02\text{ mm}}\]

Under \(40\text{ kN}\) load (\(x = 3\text{ m}\)):

\[EI \, y_2 = -10(3)^3 + 163.333(3) + 8(2)^3 = 284 \implies y_2 = \frac{284}{17000} = \mathbf{16.71\text{ mm}}\]
4. Point & Value of Maximum Deflection

Slope \(\frac{dy}{dx} = 0\) for \(1 \le x \le 3\):

\[-30x^2 + 163.333 + 24(x - 1)^2 = 0 \implies 18x^2 + 144x - 562 = 0 \implies x = \mathbf{2.87\text{ m}}\]
\[y_{\max} = \frac{284.68}{17000} = \mathbf{16.75\text{ mm}}\]
Deflections: \(y_1 = 9.02\text{ mm}\), \(y_2 = 16.71\text{ mm}\). Maximum deflection: \(16.75\text{ mm}\) at \(2.87\text{ m}\) from left support.

Consider a cantilever beam of length \(L\) fixed at \(x=0\) and carrying a point load \(P\) at the free end \(x=L\).

1. Differential Equation & Moment

Bending moment at distance \(x\) from fixed end: \(M(x) = -P(L - x)\)

\[EI \frac{d^2y}{dx^2} = -PL + Px\]
2. Slope Integration
\[EI \frac{dy}{dx} = -PLx + \frac{Px^2}{2} + C_1\]

Boundary condition at fixed end (\(x=0, \frac{dy}{dx}=0\)) gives \(C_1 = 0\).

\[\theta(x) = \frac{dy}{dx} = \frac{P}{2EI}(x^2 - 2Lx)\]
3. Deflection Integration
\[EI \, y = -\frac{PLx^2}{2} + \frac{Px^3}{6} + C_2\]

Boundary condition at fixed end (\(x=0, y=0\)) gives \(C_2 = 0\).

\[y(x) = \frac{Px^2}{6EI}(3L - x) \quad \text{(downward)}\]
4. Values at Free End (\(x=L\))
\[\theta_{\max} = \frac{PL^2}{2EI}, \quad y_{\max} = \frac{PL^3}{3EI}\]
Maximum Slope: \(\displaystyle\theta_{\max} = \frac{PL^2}{2EI}\). Maximum Deflection: \(\displaystyle y_{\max} = \frac{PL^3}{3EI}\).

Given: \(L = 3\text{ m}\), \(w = 10\text{ kN/m}\), \(E = 200\text{ GPa} = 200 \times 10^6\text{ kN/m}^2\), \(I = 80 \times 10^6\text{ mm}^4 = 80 \times 10^{-6}\text{ m}^4\).

1. Flexural Rigidity (\(EI\))
\[EI = (200 \times 10^6) \times (80 \times 10^{-6}) = 16{,}000\text{ kN}\cdot\text{m}^2\]
2. Free End Deflection Formula

For a cantilever beam under full UDL \(w\):

\[y_{\max} = \frac{w L^4}{8 EI}\]
3. Calculation
\[y_{\max} = \frac{10 \times (3)^4}{8 \times 16{,}000} = \frac{810}{128{,}000} = 0.006328125\text{ m} = \mathbf{6.33\text{ mm}}\]
Deflection at free end: \(y_{\max} = \mathbf{6.33\text{ mm}}\) (downward).
