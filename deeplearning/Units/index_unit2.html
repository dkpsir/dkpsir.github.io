2.2 Optimization

Optimization is the process of finding the best values of weights and biases that minimize the loss function during neural network training. The objective is to reduce the prediction error and improve the model's prediction accuracy.

  • Training begins with randomly initialized weights and biases.
  • The optimizer updates the weights and biases to reduce the loss.
  • The process is repeated until the loss reaches a minimum or converges.
  • Lower loss indicates better prediction accuracy.
  • Optimization enables neural networks to learn efficiently.

Key Observations

  • The 3D Loss Surface represents the loss function.
  • The yellow arrows indicate the optimization path.
  • The lowest point represents the minimum loss.
  • The Contour Plot provides the top view of the optimization process.
  • The optimizer continuously updates the parameters to move towards the minimum loss.

Classification of Optimization Techniques

Category Algorithms Learning Rate Behavior Direction Improvement Remarks
Fixed Learning Rate Methods 2.3 Gradient Descent Single constant α ❌ No Same step size for all parameters
Adaptive Learning Rate Methods AdaGrad
RMSProp
AdaDelta 		Adaptive α ❌ No Learning rate adjusts automatically
Momentum-Based Methods Nesterov Accelerated Gradient (NAG) Single α (global) ✅ Yes Faster and smoother convergence
Adaptive + Momentum Methods Adam Adaptive α ✅ Yes Combines adaptivity and momentum

Key Observations

  • Gradient Descent uses a fixed learning rate.
  • AdaGrad, RMSProp and AdaDelta automatically adjust the learning rate.
  • Nesterov Accelerated Gradient (NAG) improves the search direction using momentum.
  • Adam combines adaptive learning rate with momentum for faster and stable convergence.
  • Adaptive optimization methods generally converge faster than fixed learning rate methods.
