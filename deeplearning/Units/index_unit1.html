1.6 Thresholding Logic

Definition

Thresholding logic is a decision-making rule that compares a value with a predefined threshold (θ) and produces an output based on whether the value crosses that threshold.

Basic Thresholding Rule

For an input value x:

           ┌ 1 , if x ≥ θ
y = f(x) = │
           └ 0 , if x < θ
  • θ (theta) → Threshold value
  • Converts continuous values into binary decisions.

Thresholding in Neural Networks (M–P Neuron / Perceptron)

Step-by-step Logic

  1. Multiply inputs with weights.
  2. Compute the weighted sum.
  3. Compare the weighted sum with the threshold.
  4. Generate the output.

This is equivalent to a Step Activation Function.

Thresholding in Image Processing

  • Pixel values range from 0 to 255.
  • Choose a threshold T.
  • Pixel ≥ T → White
  • Pixel < T → Black

1.10 Activation Functions

Activation Functions

  • Activation functions determine the output of a neuron based on its net input.
  • They introduce non-linearity, enabling neural networks to learn complex patterns and solve non-linear problems.
  • They control the flow of information from one layer to the next during forward propagation.
  • Different activation functions are suitable for different layers and applications.
  • Common Activation Functions:
    • Binary Step Function
    • Bipolar Step Function
    • Sigmoid Function
    • Hyperbolic Tangent (Tanh) Function
    • ReLU (Rectified Linear Unit)
    • Leaky ReLU
    • Softmax Function
