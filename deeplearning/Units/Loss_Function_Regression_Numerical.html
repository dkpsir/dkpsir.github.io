Loss Function Calculation — Regression

Numerical Problem

A regression model predicts the output for 5 samples as shown below. Calculate:
  1. Mean Absolute Error (MAE)
  2. Sum of Squared Errors (SSE)
  3. Mean Squared Error (MSE)
Sample Actual Value
y		 Predicted Value
ŷ		 Error
y − ŷ		 |y − ŷ| (y − ŷ)²
1109111
21214−224
31513224
41820−224
52017339
Total 1022

Step 1: Mean Absolute Error (MAE)

MAE is the average of the absolute errors.

MAE = (1/n) Σ |yᵢ − ŷᵢ|

From the table:

Σ |yᵢ − ŷᵢ| = 10
n = 5
MAE = 10 / 5 = 2
MAE = 2.0

Step 2: Sum of Squared Errors (SSE)

SSE is the total of the squared errors.

SSE = Σ (yᵢ − ŷᵢ)²
SSE = 1 + 4 + 4 + 4 + 9
SSE = 22
SSE = 22

Step 3: Mean Squared Error (MSE)

MSE is the average of the squared errors.

MSE = (1/n) Σ (yᵢ − ŷᵢ)²
MSE = SSE / n
MSE = 22 / 5 = 4.4
MSE = 4.4

Final Answer

Loss Function Value
Mean Absolute Error (MAE)2.0
Sum of Squared Errors (SSE)22
Mean Squared Error (MSE)4.4
Important:
MAE → average magnitude of error
SSE → total squared error
MSE → average squared error
