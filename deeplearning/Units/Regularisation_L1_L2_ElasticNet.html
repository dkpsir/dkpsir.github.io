Regularisation — L1, L2 and Elastic Net

Numerical Problem

Consider the regression model
ŷ = wx + b
with the following three training samples. Calculate the loss without regularisation and then calculate the objective value with L1, L2 and Elastic Net regularisation.

Given model parametersw = 1.5, b = 0
MSE = (1/n) Σ(y−ŷ)²
λ = 0.1    for L1 and L2
λ₁ = 0.1,   λ₂ = 0.1    for Elastic Net

Step 1: Loss Without Regularisation

MSE = (0.25 + 1.00 + 2.25) / 3
MSE = 3.50 / 3 = 1.1667
Loss without regularisation = 1.1667
Physical meaning: This is the average squared prediction error of the model when no penalty is imposed on the weights.

Step 2: L1 Regularisation

L1 adds a penalty proportional to the absolute value of the weight.

LL1 = MSE + λ|w|
Penalty = 0.1|1.5| = 0.15
LL1 = 1.1667 + 0.15 = 1.3167
L1 Objective = 1.3167
Physical meaning: The model now pays an additional cost for having a non-zero weight. L1 encourages some weights to become exactly zero, producing a sparse model.

Step 3: L2 Regularisation

L2 adds a penalty proportional to the square of the weight.

LL2 = MSE + λw²
Penalty = 0.1(1.5)² = 0.1(2.25) = 0.225
LL2 = 1.1667 + 0.225 = 1.3917
L2 Objective = 1.3917
Physical meaning: Larger weights receive a larger penalty. L2 therefore encourages weights to become smaller and usually keeps them non-zero.

Step 4: Elastic Net Regularisation

Elastic Net combines L1 and L2 penalties.

LEN = MSE + λ₁|w| + λ₂w²
L1 penalty = 0.1(1.5) = 0.15
L2 penalty = 0.1(1.5)² = 0.225
LEN = 1.1667 + 0.15 + 0.225 = 1.5417
Elastic Net Objective = 1.5417
Physical meaning: Elastic Net simultaneously applies the sparsity tendency of L1 and the weight-shrinking tendency of L2.
