Adam — Numerical Problem

Common Numerical Problem

Consider a simple one-parameter optimization problem with loss function:
L(w) = (w − 3)²
The initial parameter is w = 0 and the learning rate is α = 0.1. Calculate the gradient, perform one parameter update using the specified optimization technique, and calculate the new loss.
QuantityValue
Loss functionL(w) = (w − 3)²
Initial parameterw₀ = 0
Learning rateα = 0.1
Initial lossL(0) = 9
Initial gradient∂L/∂w = 2(w−3) = −6

Step 1: Calculate Gradient

g = ∂L/∂w = 2(w−3) = −6

Step 2: First Moment

m = β₁mold + (1−β₁)g
β₁=0.9:   m = 0.9(0)+0.1(−6) = −0.6

Step 3: Second Moment

v = β₂vold + (1−β₂)g²
β₂=0.999:   v = 0.999(0)+0.001(36) = 0.036

Step 4: Bias Correction

m̂ = m/(1−β₁) = −0.6/0.1 = −6
v̂ = v/(1−β₂) = 0.036/0.001 = 36

Step 5: Parameter Update

wnew = w − α m̂/(√v̂+ε)
wnew = 0 − 0.1(−6)/6 = 0.1

Step 6: Calculate New Loss

L(0.1) = (0.1−3)² = 8.41

Physical meaning:
Adam combines a first-moment estimate of the gradient with a second-moment estimate of the squared gradient. After bias correction, the first update moves the parameter from 0 to 0.1 and reduces the loss from 9 to 8.41.
Teaching point:
Adam combines adaptive learning rates with momentum-like first-moment information. Bias correction is especially important in the early iterations when the moment estimates start from zero.
