Gradient Descent — Numerical Problem

Common Numerical Problem

Consider a simple one-parameter optimization problem with loss function:
L(w) = (w − 3)²
The initial parameter is w = 0 and the learning rate is α = 0.1. Calculate the gradient, perform one parameter update using the specified optimization technique, and calculate the new loss.
QuantityValue
Loss functionL(w) = (w − 3)²
Initial parameterw₀ = 0
Learning rateα = 0.1
Initial lossL(0) = 9
Initial gradient∂L/∂w = 2(w−3) = −6

Step 1: Calculate Gradient

∂L/∂w = 2(w−3)
At w=0:   ∂L/∂w = 2(0−3) = −6

Step 2: Update Parameter

wnew = wold − α(∂L/∂w)
wnew = 0 − 0.1(−6) = 0.6

Step 3: Calculate New Loss

L(0.6) = (0.6−3)² = (−2.4)² = 5.76

Physical meaning:
The parameter moves from 0 toward the minimum at w=3. The loss falls from 9 to 5.76, showing that the update has moved the model in the direction of lower error.
Teaching point:
Gradient Descent uses the same learning rate α for the parameter and moves directly opposite to the current gradient.
