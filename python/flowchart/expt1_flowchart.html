Experiment 1 – Reactions at Supports of a Simply Supported Beam

Experiment 1 – Flow Chart
START
↓
Input Beam Span L (m)
↓
Input Three Point Loads P₁, P₂, P₃ (kN)
↓
Input Positions of Loads from Left Support A a₁, a₂, a₃ (m)
↓
Calculate Right Support Reaction RB = (P₁a₁ + P₂a₂ + P₃a₃) / L
↓
Calculate Left Support Reaction RA = P₁ + P₂ + P₃ − RB
↓
Display Support Reactions RA and RB
↓
END
Complete Python Program
# Program to calculate reactions of a simply supported beam
# carrying three point loads

# Input beam span
L = float(input("Enter the span of the beam (m): "))

# Input point loads
P1 = float(input("Enter First Point Load P1 (kN): "))
P2 = float(input("Enter Second Point Load P2 (kN): "))
P3 = float(input("Enter Third Point Load P3 (kN): "))

# Input distances from left support A
a1 = float(input("Enter distance of P1 from Left Support A (m): "))
a2 = float(input("Enter distance of P2 from Left Support A (m): "))
a3 = float(input("Enter distance of P3 from Left Support A (m): "))

# Calculate reactions
RB = (P1 * a1 + P2 * a2 + P3 * a3) / L
RA = P1 + P2 + P3 - RB

# Display results
print("\n------ REACTIONS AT SUPPORTS ------")
print("Reaction at Left Support (RA) =", round(RA, 2), "kN")
print("Reaction at Right Support (RB) =", round(RB, 2), "kN")
Python Program – Line-by-Line Explanation
Python Statement Purpose What it does
L = float(input("Enter the span of the beam (m): ")) Input Accepts the beam span from the user and converts the entered value into a floating-point number.
P1 = float(input("Enter First Point Load P1 (kN): ")) Input Accepts the first point load acting on the beam in kN.
P2 = float(input("Enter Second Point Load P2 (kN): ")) Input Accepts the second point load acting on the beam in kN.
P3 = float(input("Enter Third Point Load P3 (kN): ")) Input Accepts the third point load acting on the beam in kN.
a1 = float(input("Enter distance of P1 from Left Support A (m): ")) Input Accepts the distance of the first point load P1 from the left support A.
a2 = float(input("Enter distance of P2 from Left Support A (m): ")) Input Accepts the distance of the second point load P2 from the left support A.
a3 = float(input("Enter distance of P3 from Left Support A (m): ")) Input Accepts the distance of the third point load P3 from the left support A.
RB = (P1 * a1 + P2 * a2 + P3 * a3) / L Calculation Calculates the reaction at the right support B by taking moments about the left support A.
RA = P1 + P2 + P3 - RB Calculation Calculates the reaction at the left support A using vertical force equilibrium.
print("\n----- REACTIONS AT SUPPORTS -----") Output Prints a heading to identify the support reaction results.
print("Reaction at Left Support (RA) =", round(RA, 2), "kN") Output Displays the calculated reaction at the left support A, rounded to two decimal places.
print("Reaction at Right Support (RB) =", round(RB, 2), "kN") Output Displays the calculated reaction at the right support B, rounded to two decimal places.
Concept used: The program determines the two support reactions using moment equilibrium about support A and vertical force equilibrium.
