Complete Python Program
import math

# Program to calculate Torsion and Twist Angle of Shafts

print("--- TORSION CALCULATOR FOR CIRCULAR SHAFTS ---")
print("1. Solid Shaft")
print("2. Hollow Shaft")

choice = int(input("Select Shaft Type (1 or 2): "))

# Input Torque, Length, and Modulus of Rigidity
T_kNm = float(input("Enter Transmitted Torque T (kN·m): "))
L_m = float(input("Enter Length of Shaft L (m): "))
G_GPa = float(input("Enter Shear Modulus G (GPa): "))

# Unit Conversions
T_Nmm = T_kNm * 1e6     # kN·m to N·mm
L_mm = L_m * 1000        # m to mm
G_Nmm2 = G_GPa * 1000    # GPa to N/mm²

if choice == 1:
    d = float(input("Enter Diameter d (mm): "))
    J = (math.pi * (d ** 4)) / 32
    R = d / 2
    shaft_type = "Solid Shaft"
elif choice == 2:
    do = float(input("Enter Outer Diameter d_o (mm): "))
    di = float(input("Enter Inner Diameter d_i (mm): "))
    J = (math.pi * (do ** 4 - di ** 4)) / 32
    R = do / 2
    shaft_type = "Hollow Shaft"
else:
    print("Invalid Selection!")
    exit()

# Calculate Shear Stress (tau) and Angle of Twist (theta)
tau_max = (T_Nmm * R) / J           # N/mm² or MPa
theta_rad = (T_Nmm * L_mm) / (G_Nmm2 * J) # radians
theta_deg = math.degrees(theta_rad) # degrees

# Display Results
print(f"\n------ RESULTS ({shaft_type.upper()}) ------")
print(f"Polar Moment of Inertia (J): {J:.2f} mm⁴")
print(f"Max Shear Stress (τ_max)   : {tau_max:.2f} MPa")
print(f"Angle of Twist (θ)        : {theta_rad:.6f} rad ({theta_deg:.4f}°)")
Python Program – Line-by-Line Explanation
Python Statement Purpose What it does
import math Import Imports the math module to access math.pi and trigonometric angle conversion functions.
T_Nmm = T_kNm * 1e6 Conversion Converts torque from $\text{kN}\cdot\text{m}$ to $\text{N}\cdot\text{mm}$ ($1\text{ kN}\cdot\text{m} = 10^6\text{ N}\cdot\text{mm}$).
G_Nmm2 = G_GPa * 1000 Conversion Converts Modulus of Rigidity from $\text{GPa}$ to $\text{N/mm}^2$ ($1\text{ GPa} = 1000\text{ N/mm}^2$).
J = (math.pi * (d ** 4)) / 32 Calculation Computes Polar Moment of Inertia for a solid shaft: $J = \frac{\pi d^4}{32}$.
J = (math.pi * (do ** 4 - di ** 4)) / 32 Calculation Computes Polar Moment of Inertia for a hollow shaft: $J = \frac{\pi(d_o^4 - d_i^4)}{32}$.
tau_max = (T_Nmm * R) / J Calculation Calculates maximum shear stress at outer radius using torsion formula: $\tau_{\max} = \frac{T \cdot R}{J}$.
theta_rad = (T_Nmm * L_mm) / (G_Nmm2 * J) Calculation Computes angle of twist in radians using elastic torsion equation: $\theta = \frac{T \cdot L}{G \cdot J}$.
theta_deg = math.degrees(theta_rad) Conversion Converts twist angle from radians to degrees ($\text{deg} = \text{rad} \times \frac{180}{\pi}$).
Torsion Theory: According to the elastic torsion equation $\frac{T}{J} = \frac{\tau}{R} = \frac{G \cdot \theta}{L}$, maximum shear stress occurs at the outermost layer ($R = d/2$ or $R = d_o/2$).
