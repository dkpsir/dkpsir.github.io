Complete Python Program
# Program to calculate SF and BM of a simply supported
# beam carrying Point Loads and UDL

# Input beam span
L = float(input("Enter length of the beam L (m): "))

# Input point loads and positions
P1 = float(input("Enter point load P1 (kN): "))
a1 = float(input("Enter distance of P1 from Left Support A (m): "))

P2 = float(input("Enter point load P2 (kN): "))
a2 = float(input("Enter distance of P2 from Left Support A (m): "))

# Input UDL
w = float(input("Enter UDL intensity w (kN/m): "))

# Calculate support reactions
RB = (P1 * a1 + P2 * a2 + w * (L ** 2) / 2) / L
RA = P1 + P2 + (w * L) - RB

# Input section x
x = float(input("\nEnter distance x from Left Support A (m): "))

# Calculate Shear Force (SF) at x
sf_p1 = P1 if a1 <= x else 0.0
sf_p2 = P2 if a2 <= x else 0.0
sf_udl = w * x
SF_x = RA - (sf_p1 + sf_p2 + sf_udl)

# Calculate Bending Moment (BM) at x
bm_p1 = P1 * (x - a1) if a1 <= x else 0.0
bm_p2 = P2 * (x - a2) if a2 <= x else 0.0
bm_udl = w * (x ** 2) / 2
BM_x = (RA * x) - (bm_p1 + bm_p2 + bm_udl)

# Display results
print("\n------ RESULTS SUMMARY ------")
print("Reaction RA =", round(RA, 2), "kN")
print("Reaction RB =", round(RB, 2), "kN")
print(f"Shear Force at x = {x} m:", round(SF_x, 2), "kN")
print(f"Bending Moment at x = {x} m:", round(BM_x, 2), "kN·m")
Python Program – Line-by-Line Explanation
Python Statement Purpose What it does
L = float(input("Enter length of the beam L (m): ")) Input Accepts the overall length/span of the beam in meters.
P1 = float(input("Enter point load P1 (kN): ")) Input Accepts the magnitude of the first point load P1 in kN.
a1 = float(input("Enter distance of P1...")) Input Accepts the distance of point load P1 measured from Left Support A.
w = float(input("Enter UDL intensity w (kN/m): ")) Input Accepts the uniformly distributed load (UDL) rate across the beam.
RB = (P1 * a1 + P2 * a2 + w * (L ** 2) / 2) / L Calculation Computes Right Support reaction RB using moment equilibrium about Left Support A.
RA = P1 + P2 + (w * L) - RB Calculation Computes Left Support reaction RA using vertical force equilibrium (ΣFy = 0).
x = float(input("Enter distance x...")) Input Accepts the section position x from Support A where SF and BM need to be evaluated.
sf_p1 = P1 if a1 <= x else 0.0 Conditional Includes load P1 in shear force calculation only if it lies to the left of section x.
sf_udl = w * x Calculation Calculates the accumulated force due to UDL up to section x.
SF_x = RA - (sf_p1 + sf_p2 + sf_udl) Calculation Calculates the net Shear Force (SF) at section x by subtracting forces acting downward.
bm_p1 = P1 * (x - a1) if a1 <= x else 0.0 Conditional Calculates bending moment contribution of P1 about section x if a1 ≤ x.
bm_udl = w * (x ** 2) / 2 Calculation Calculates bending moment contribution of UDL acting to the left of section x.
BM_x = (RA * x) - (bm_p1 + bm_p2 + bm_udl) Calculation Calculates net Bending Moment (BM) at section x.
print(...) Output Outputs calculated reactions, shear force, and bending moment rounded to 2 decimal places.
Concept used: At any section x, Shear Force (SF) is the algebraic sum of all vertical forces to the left of x, and Bending Moment (BM) is the algebraic sum of moments of all forces to the left of x.
