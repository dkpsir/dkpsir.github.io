Complete Python Program
import math

# Program to calculate Slope and Maximum Deflection of Beams

print("--- BEAM DEFLECTION CALCULATOR ---")
print("1. Simply Supported Beam (Central Point Load)")
print("2. Cantilever Beam (Point Load at Free End)")

choice = int(input("Select Beam Type (1 or 2): "))

# Input Beam Geometry and Loading
L = float(input("Enter length of the beam L (m): "))
P = float(input("Enter point load P (kN): "))
E_GPa = float(input("Enter Modulus of Elasticity E (GPa): "))
b = float(input("Enter section width b (mm): "))
h = float(input("Enter section height h (mm): "))

# Unit Conversions
P_N = P * 1000            # kN to N
L_mm = L * 1000           # m to mm
E_Nmm2 = E_GPa * 1000     # GPa to N/mm²

# Calculate Moment of Inertia (I) for rectangular section
I = (b * (h ** 3)) / 12   # mm⁴

# Calculation based on Beam Type
if choice == 1:
    # Simply Supported Beam
    theta_rad = (P_N * (L_mm ** 2)) / (16 * E_Nmm2 * I)
    delta_max = (P_N * (L_mm ** 3)) / (48 * E_Nmm2 * I)
    beam_name = "Simply Supported Beam"
elif choice == 2:
    # Cantilever Beam
    theta_rad = (P_N * (L_mm ** 2)) / (2 * E_Nmm2 * I)
    delta_max = (P_N * (L_mm ** 3)) / (3 * E_Nmm2 * I)
    beam_name = "Cantilever Beam"
else:
    print("Invalid choice!")
    exit()

# Convert slope from radians to degrees
theta_deg = math.degrees(theta_rad)

# Display Results
print(f"\n------ RESULTS ({beam_name.upper()}) ------")
print(f"Moment of Inertia (I) : {I:.2f} mm⁴")
print(f"Maximum Slope (θ)     : {theta_rad:.6f} rad ({theta_deg:.4f}°)")
print(f"Maximum Deflection (δ): {delta_max:.4f} mm")
Python Program – Line-by-Line Explanation
Python Statement Purpose What it does
import math Import Loads Python's built-in math module to convert radians into degrees.
choice = int(input("Select Beam Type (1 or 2): ")) Input Captures user selection to determine whether to compute a Simply Supported or Cantilever beam.
L = float(input("Enter length of the beam L (m): ")) Input Reads the span length $L$ in meters.
P_N = P * 1000 / L_mm = L * 1000 Conversion Converts input values to standard unit system ($\text{N}$ and $\text{mm}$).
E_Nmm2 = E_GPa * 1000 Conversion Converts Young's Modulus from $\text{GPa}$ ($10^9\text{ N/m}^2$) to $\text{N/mm}^2$ ($1\text{ GPa} = 1000\text{ N/mm}^2$).
I = (b * (h ** 3)) / 12 Calculation Computes second moment of area (Moment of Inertia) for a rectangular section: $I = \frac{b \cdot h^3}{12}$.
theta_rad = (P_N * (L_mm ** 2)) / (16 * E_Nmm2 * I) Calculation Calculates maximum slope $\theta = \frac{P L^2}{16 E I}$ at the supports for a Simply Supported Beam.
delta_max = (P_N * (L_mm ** 3)) / (48 * E_Nmm2 * I) Calculation Calculates maximum center deflection $\delta = \frac{P L^3}{48 E I}$ for a Simply Supported Beam.
theta_rad = (P_N * (L_mm ** 2)) / (2 * E_Nmm2 * I) Calculation Calculates maximum slope $\theta = \frac{P L^2}{2 E I}$ at the free end for a Cantilever Beam.
delta_max = (P_N * (L_mm ** 3)) / (3 * E_Nmm2 * I) Calculation Calculates maximum deflection $\delta = \frac{P L^3}{3 E I}$ at the free end for a Cantilever Beam.
theta_deg = math.degrees(theta_rad) Conversion Converts maximum slope angle from radians to degrees ($\text{deg} = \text{rad} \times \frac{180}{\pi}$).
print(f"Maximum Deflection (δ): {delta_max:.4f} mm") Output Displays formatted results rounded to standard engineering precision.
Key Engineering Standard: All calculations perform consistent unit conversions to $\text{N}$ and $\text{mm}$ prior to evaluation so that Moment of Inertia ($I$) remains in $\text{mm}^4$ and Deflection ($\delta$) outputs directly in $\text{mm}$.
