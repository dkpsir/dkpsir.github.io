Experiment 9 – Analysis of Engine Test Data using NumPy and Pandas

Experiment 9 – Flow Chart and Python Program
Complete Python Program
import numpy as np
import pandas as pd

# Engine test data
data = {
    "Engine": ["E1", "E2", "E3", "E4", "E5"],
    "Temperature_C": [85, 92, 105, 88, 110],
    "Fuel_Consumption_Lph": [2.5, 2.8, 3.2, 2.6, 3.5],
    "Power_kW": [5.0, 5.5, 6.0, 5.2, 6.5]
}

df = pd.DataFrame(data)

# Calculate overall averages using NumPy
avg_temp = np.mean(df["Temperature_C"])
avg_fuel = np.mean(df["Fuel_Consumption_Lph"])
avg_power = np.mean(df["Power_kW"])

# Identify engines exceeding the temperature limit
temperature_limit = 100
df["Status"] = np.where(
    df["Temperature_C"] > temperature_limit,
    "High Temperature",
    "Normal"
)

print("ENGINE PERFORMANCE ANALYSIS")
print(df.to_string(index=False))

print("\nAverage Temperature:", round(avg_temp, 2), "°C")
print("Average Fuel Consumption:", round(avg_fuel, 2), "L/h")
print("Average Power:", round(avg_power, 2), "kW")

print("\nEngines requiring temperature investigation:")
print(df[df["Status"] == "High Temperature"]["Engine"].to_list())

Python Code Line / Snippet Concept Detailed Explanation

df = pd.DataFrame(data) DataFrame Transforms the structured dictionary into a Pandas DataFrame, creating a 2D table of rows and columns.
avg_temp = np.mean(df["Temperature_C"]) Calculate Mean Calculates the arithmetic average of all the engines' temperatures using NumPy and assigns it to a variable.
temperature_limit = 100 Variable Assignment Defines a numerical threshold limit for safe engine operating temperatures.
df["Status"] = np.where(...) Conditional Selection Creates a new column 'Status' and assigns a value based on a condition applied to each row.
df["Temperature_C"] > temperature_limit Condition The logical check verifying if an engine's temperature exceeds 100 °C. If True, it assigns "High Temperature", otherwise "Normal".
print(df.to_string(index=False)) Display Data Prints the entire DataFrame cleanly by hiding the default numerical row indices.
round(avg_temp, 2) Round a Value Rounds the calculated average temperature to two decimal places for formatted output.
df[df["Status"] == "High Temperature"] Filter DataFrame Filters the DataFrame to return only the rows (engines) where the status is flagged as "High Temperature".
...["Engine"].to_list() List Conversion Extracts the "Engine" column from the filtered DataFrame and converts that Series into a standard Python list.
Important: The flow chart and explanations above map directly to the engine test data analysis program. The test values are hard-coded in a dictionary, therefore no keyboard input is required during execution.
