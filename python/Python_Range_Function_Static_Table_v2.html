Python range() Function in for Loop

Syntax Description Example Output
range(stop) Starts from 0, increments by 1, stops before stop. for i in range(5): 0 1 2 3 4
range(start, stop) Starts from start, increments by 1, stops before stop. for i in range(2, 7): 2 3 4 5 6
range(start, stop, step) Starts from start, increments/decrements by step, stops before stop. for i in range(2, 20, 3): 2 5 8 11 14 17
Note: The stop value is excluded from the output.
