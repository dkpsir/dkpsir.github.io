1. Basic Theory

A for loop is used to execute a block of statements repeatedly for each value in a sequence or range of values.

Basic idea:
Start → Take a value → Execute the statements → Take the next value → Repeat → Stop when the sequence is exhausted.

The range() function is commonly used with a for loop when we want to repeat a statement a specified number of times.

2. for Loop – Syntax

General Syntax
for variable in sequence:
    statement
for

Keyword used to start the loop.

variable

Receives each value during the iteration.

in

Connects the loop variable with the sequence.

sequence

Values over which the loop iterates.

The statements inside the loop must be indented.

3. range() Function

Three Common Forms
range(stop)    |    range(start, stop)    |    range(start, stop, step)
Important: The stop value is not included.
ExampleDescriptionOutput

5. for Loop with if Condition

A for loop can be combined with an if statement to select particular values during iteration. 

for i in range(1, 11):
    if i % 3 == 0:
        print(i)

Output: 3 6 9

6. Nested for Loops

A nested for loop is a loop placed inside another loop. For every iteration of the outer loop, the inner loop executes completely. 

for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)

Output:
1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3

How to solve tricky for-loop questions: First write down the values produced by range(). Then trace the outer loop one iteration at a time. If there is an if, break, or continue, apply it at the exact point where it occurs. For nested loops, complete the inner loop for every value of the outer loop.

9. Important Points to Remember

  • A for loop repeats a block of statements for each value in a sequence.
  • range() is commonly used to generate integer values for a loop.
  • The stop value in range() is excluded.
  • The step controls the increment or decrement.
  • Loop statements must be properly indented.
  • An if statement can be placed inside a for loop.
  • A nested for loop contains one loop inside another.
  • break terminates the loop.
  • continue skips the current iteration.
  • Always trace the values of the loop variable when solving output-based questions.
