1. Basic Theory

A while loop repeatedly executes a block of statements as long as a given condition is True.

Initialize
→
Check Condition
→
Execute Statements
→
Update
↺

The condition is checked before every iteration. When the condition becomes False, the loop stops.

Basic idea:
Initialize → Check condition → Execute → Update → Check again → Stop when the condition becomes False.

2. while Loop – Syntax

General Syntax
while condition:
    statement
    update
while

Keyword used to begin the loop.

condition

Boolean condition checked before every iteration.

statement

Block of statements executed when the condition is True.

update

Changes the loop variable so that the loop can eventually stop.

Important: A while loop must normally have a suitable update. If the condition never becomes False, an infinite loop may occur.

3. Basic while Loop Example

Python Program

i = 1

while i <= 5:
    print(i)
    i = i + 1

Explanation

Initially, i = 1.

The condition i <= 5 is checked. If it is True, the value of i is printed and then i is increased by 1.

The loop continues until i becomes 6. At that point, i <= 5 is False and the loop stops.
Output: 1 2 3 4 5

4. while Loop with if Condition

Python Program

i = 1

while i <= 10:
    if i % 2 == 0:
        print(i)
    i = i + 1

Explanation

The while loop generates the numbers from 1 to 10. Inside the loop, the if condition checks whether the current value is even.

Only values for which i % 2 == 0 are printed. The update i = i + 1 moves the loop to the next number.
Output: 2 4 6 8 10

5. Frequently Used General Programs

The following examples are common beginner programs for understanding the practical use of a while loop. Each program is kept within the concepts introduced so far.

Program 1 – Sum of Numbers from 1 to n

n = int(input("Enter n: "))

i = 1
s = 0

while i <= n:
    s = s + i
    i = i + 1

print("Sum =", s)
Explanation:
The variable i starts from 1 and moves towards n. The variable s stores the running sum.

For n = 5:
s = 0 → 1 → 3 → 6 → 10 → 15.

The loop stops when i becomes 6.
Output: Sum = 15

Program 2 – Factorial of a Number

n = int(input("Enter n: "))

i = 1
fact = 1

while i <= n:
    fact = fact * i
    i = i + 1

print("Factorial =", fact)
Explanation:
The variable fact stores the running product. It starts from 1.

For n = 5:
1 × 2 × 3 × 4 × 5 = 120.

The loop repeatedly multiplies fact by the current value of i.
Output: Factorial = 120

Program 3 – Count the Digits of a Number

n = int(input("Enter n: "))

count = 0

while n > 0:
    n = n // 10
    count = count + 1

print("Number of digits =", count)
Explanation:
Integer division by 10 removes the last digit of the number. The counter is increased once for every digit removed.

For n = 12345:
12345 → 1234 → 123 → 12 → 1 → 0.

Five iterations are required, so the number has five digits.
Output: Number of digits = 5

Program 4 – Reverse a Number

n = int(input("Enter n: "))

rev = 0

while n > 0:
    digit = n % 10
    rev = rev * 10 + digit
    n = n // 10

print("Reverse =", rev)
Explanation:
n % 10 extracts the last digit.
That digit is added to the reverse number using rev = rev * 10 + digit.
Then n // 10 removes the last digit from the original number.

For n = 1234:
4 → 43 → 432 → 4321.
Output: Reverse = 4321

Program 5 – Check Whether a Number is Palindrome

n = int(input("Enter n: "))

original = n
rev = 0

while n > 0:
    digit = n % 10
    rev = rev * 10 + digit
    n = n // 10

if original == rev:
    print("Palindrome")
else:
    print("Not Palindrome")
Explanation:
First, the original number is stored because the variable n will change while the reverse is being calculated.

After reversing the number, the program compares the original number with the reversed number.

For 121, the reverse is also 121, so the number is a palindrome.
Output: Palindrome

6. Common Mistakes in while Loops

Mistake Problem Correct Approach
Forgetting the update The condition may remain True forever. Update the loop variable inside the loop.
Wrong condition The loop may stop too early or never stop. Check the condition carefully before writing the loop.
Incorrect indentation Statements may not belong to the loop. Indent all statements that must repeat.
Changing the wrong variable The loop-control variable may not progress. Update the variable used in the condition.

7. Important Points to Remember

  • A while loop repeats while its condition is True.
  • The condition is checked before every iteration.
  • Initialization should be done before the loop.
  • The loop-control variable should normally be updated inside the loop.
  • Forgetting the update can create an infinite loop.
  • A while loop is useful when the number of repetitions depends on a condition.
  • An if statement can be placed inside a while loop.
  • Indentation is required to define the loop body.
