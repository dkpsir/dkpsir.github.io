DICTIONARIES

1
Identify the error in the following program:
data = {"id": 101, "name": "Kiran"}
print(data["age"])
+
Exception & Error Trace
KeyError: 'age'
Explanation: Accessing a dictionary via direct subscript syntax d[key] raises a KeyError if the requested key does not exist. To avoid an unhandled crash, use data.get("age") which returns None or a specified default fallback.
2
Identify the error in the following program:
inner_dict = {"a": 1}
outer_dict = {}
outer_dict[inner_dict] = "Config"

print(outer_dict)
+
Exception & Error Trace
TypeError: unhashable type: 'dict'
Explanation: Dictionary keys must be immutable and hashable. Because dictionaries are mutable objects, they do not implement a hash function (__hash__ = None), resulting in a TypeError when used as keys.
3
Identify the error in the following program:
s = {1, 2, 3}
d = {s: "Numbers"}

print(d)
+
Exception & Error Trace
TypeError: unhashable type: 'set'
Explanation: A standard Python set is a mutable collection and cannot be hashed. To use a set of elements as a dictionary key, it must be wrapped into an immutable frozenset({1, 2, 3}).

Identify the error in the following program:

print(d)
+
Exception & Error Trace
AttributeError: 'dict' object has no attribute 'append'
Explanation: Dictionaries do not have an .append() or .add() method. Key-value pairs must be assigned directly via subscripting d["z"] = 30 or using d.update({"z": 30}).

Identify the error in the following program:

d = dict(pairs)

print(d)
+
Exception & Error Trace
ValueError: dictionary update sequence element #1 has length 3; 2 is required
Explanation: The dict() constructor converts an iterable of sequences only if every inner element has an exact length of 2 (representing a (key, value) pair). ("b", 2, 3) has 3 elements, raising a ValueError.

Identify the error in the following program:
words = ["hello world", "python programming"]
d = {w.split(): len(w) for w in words}

print(d)
+
Exception & Error Trace
TypeError: unhashable type: 'list'
Explanation: w.split() produces a list (e.g., ['hello', 'world']). Using the list expression as the key in the dictionary comprehension fails because lists cannot be hashed. Converting it to a tuple tuple(w.split()) resolves the error.
