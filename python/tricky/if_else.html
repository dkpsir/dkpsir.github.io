Find the output of the program.
x = 12

if x > 10:
    x = x - 4
    if x > 5:
        x = x + 10
    else:
        x = x + 20
else:
    x = x + 100

print(x)
+
Answer
Output / Error
18
Explanation: Initially x is 12, so the outer condition is True and x becomes 8. The inner condition 8 > 5 is also True, so 10 is added. The final value is 18.

    if y > 10:
        result = "A"

    result = "D"
else:
    result = "E"

+
Answer
Output / Error
18 8
C
Explanation: Initially x < y is True, so x becomes 8. x == y is True, so y becomes 5. The remaining inner branches are skipped. In the final structure x > 10 is True; y > 10 is False and y > 5 is also False, so result becomes C.
