INPUT - OUTPUT FUNCTIONS

Python Programming – Basic Concepts

1. Basic Theory

Input means accepting data from the user during program execution. In Python, the input() function is commonly used to receive input from the keyboard.

Output means displaying information, calculated results, messages, or values on the screen. In Python, the print() function is used to display output.

Basic idea:
Input → Process / Calculation → Output

In engineering programs, input statements are useful for entering quantities such as beam span, load, distance, diameter, force, pressure and temperature. Output statements display the calculated results.

2. input() Function – Syntax

General Syntax
variable = input("prompt message")
variable

Name used to store the value entered by the user.

=

Assignment operator used to store the input in the variable.

input()

Built-in function used to accept keyboard input.

"prompt message"

Message telling the user what value should be entered.

Important: The value returned by input() is normally a string. Use int() or float() when numerical calculations are required.

4. Type Conversion with input()

Since input() returns a string, numerical input should be converted before arithmetic operations.

Example: a = input("Enter first number: ") and b = input("Enter second number: ") keep both values as strings. Convert them before numerical addition.

10. Formatted Output using f-Strings

print(f"Text {variable}")
ExampleDescriptionOutput
name = "Ravi"
print(f"Name = {name}")		 Inserts the value of a variable into a string. Name = Ravi
age = 20
print(f"Age = {age}")		 Displays an integer variable using an f-string. Age = 20
price = 125.6789
print(f"Price = {price:.2f}")		 Displays a floating-point value with two decimal places. Price = 125.68
a = 10
b = 20
print(f"Sum = {a+b}")		 An expression can be placed inside the braces. Sum = 30
name = "Anu"
marks = 85
print(f"{name} scored {marks} marks")		 Multiple variables can be included in one output statement. Anu scored 85 marks
x = 7
print(f"Square = {x*x}")		 Calculates an expression while formatting the output. Square = 49
Note: f-strings are especially useful when a program needs to display variables and calculated results in a clear and readable format.

13. Important Points to Remember

  • input() accepts data from the user.
  • Input received through input() is normally a string.
  • Use int() for integer input and float() for decimal input.
  • print() displays information and results.
  • Multiple values can be displayed using commas inside print().
  • sep controls the separator between multiple values.
  • end controls what is printed at the end of a print statement.
  • f-strings provide convenient formatted output.
  • For engineering programs, always display appropriate units.
  • Use formatting such as :.2f when a result should be shown to two decimal places.
