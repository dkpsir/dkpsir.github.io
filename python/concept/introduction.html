Introduction, Variables, Data Types & Type Conversion

1. Introduction to Python

Python is a high-level, general-purpose programming language known for its simple and readable syntax. It is widely used for programming, data analysis, artificial intelligence, machine learning, automation and many other applications.

A Python program is a sequence of statements written to perform a particular task. Python allows a problem to be expressed using variables, data, operators, functions and control structures.

Basic idea:
Problem → Python Statements → Execution → Output

3. Variables

A variable is a name used to refer to a value during program execution. In Python, a variable is created when a value is assigned to it.

Assignment Syntax
variable = value
variable

Name used to refer to the stored value.

=

Assignment operator used to assign the value.

value

Data stored or referred to by the variable.

Type conversion means changing a value from one data type to another.

Common conversion functions:

8. Why Type Conversion is Needed

Program

a = input("Enter a number: ")
b = input("Enter another number: ")

print(a + b)

Explanation

  1. input() accepts the first value.
  2. The value is stored as a string.
  3. The second input is also stored as a string.
  4. + joins the two strings instead of performing numerical addition.
Input

10
20

Output

1020

What should we do? Convert the inputs to integers before performing numerical addition.

Corrected Program

a = int(input("Enter a number: "))
b = int(input("Enter another number: "))

print(a + b)

Explanation

  1. input() receives the values as strings.
  2. int() converts each string to an integer.
  3. The + operator now performs numerical addition.
  4. print() displays the result.
Input

10
20

Output

30

10. Basic Python Programs

Program 1 – Display a Value

name = "Ravi"
age = 20

print(name)
print(age)

Explanation

The variables name and age store a string and an integer. Two print() statements display their values.

Input

None – values are already assigned.

Output

Ravi
20

Program 2 – Add Two Numbers

a = 10
b = 5
sum_value = a + b

print("Sum =", sum_value)

Explanation

Two integer values are stored in a and b. The + operator calculates their sum, which is stored in sum_value.

Input

None – values are assigned in the program.

Output

Sum = 15

Program 3 – Square of a Number

x = 7
square = x * x

print("Square =", square)

Explanation

The value 7 is stored in x. Multiplying x by itself calculates its square.

Input

None – x is assigned the value 7.

Output

Square = 49

Program 4 – Convert Text to Number

value = "25"
number = int(value)

print("Number + 5 =", number + 5)

Explanation

value contains the text "25". The int() function converts it to the integer 25, allowing numerical addition.

Input

The string "25" is assigned in the program.

Output

Number + 5 = 30

Program 5 – Formatted Decimal Output

price = 125.6789

print(f"Price = {price:.2f}")

Explanation

The value is a float. The f-string inserts the variable into the output, while :.2f displays exactly two digits after the decimal point.

Input

None – the value is assigned in the program.

Output

Price = 125.68

11. Complete Example – Personal Details

Python Program

name = input("Enter name: ")
age = int(input("Enter age: "))
height = float(input("Enter height: "))

print("\n----- DETAILS -----")
print("Name =", name)
print("Age =", age)
print("Height =", height)
print("Age type =", type(age))
print("Height type =", type(height))

Explanation

  1. name receives text from the user.
  2. age is converted from input text to an integer using int().
  3. height is converted to a floating-point value using float().
  4. The print() statements display the stored values.
  5. type() verifies the data type of the numeric variables.
Input

Ravi
20
1.72

Output

----- DETAILS -----
Name = Ravi
Age = 20
Height = 1.72
Age type = <class 'int'>
Height type = <class 'float'>

Program pattern: Input → Convert when necessary → Store in variables → Process → Display output → Check results.

12. Important Points to Remember

  • Python is a high-level, general-purpose programming language.
  • A variable is a name used to refer to a value.
  • Common basic data types are int, float, str and bool.
  • Use type() to check the type of a value.
  • Use int(), float(), str() and bool() for explicit type conversion.
  • input() normally returns a string, so numerical input often needs conversion.
  • Use meaningful variable names to make programs easier to understand.
  • When showing a Python program, understand what each statement does before looking at the output.
