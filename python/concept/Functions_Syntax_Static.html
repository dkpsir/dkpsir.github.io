1. Basic Theory

A user defined function is a block of Python statements created by the programmer to perform a particular task. A function can be called whenever that task is required.

Basic idea:
Define the function → Call the function → Execute the function body → Get the required result.

Functions make programs easier to understand, reduce repetition and allow a large program to be divided into smaller, manageable parts.

2. Defining and Calling a Function

General Syntax
def function_name(parameters):
    statements

The keyword def is used to define a function. The function name is followed by parentheses and a colon. The statements inside the function must be indented.

The function is executed only when it is called.

3. Types of Functions Used in This Topic

Type Example Basic Idea
Without argument, without return def greet(): Function receives no value and does not return a result.
With a single argument def square(n): One value is passed to the function.
With multiple arguments def add(a,b): Two or more values can be passed.
With return value return result The function sends a result back to the calling statement.
With arguments and return def add(a,b): return a+b Values are received, processed and a result is returned.
Important: print() displays a result, whereas return sends a result back to the place where the function was called.

4. Frequently Used General Programs

The following programs demonstrate the main function concepts: function without arguments, single and multiple arguments, return values, conditional statements and loops.

Program 1 – Function Without Argument and Without Return

Python Program

def greet():
    print("Hello, welcome to Python")

greet()
Explanation:
The function greet() is defined without any arguments. Therefore, no value is passed when the function is called.

There is also no return statement. The function directly displays the message using print().

The statement greet() calls the function and executes its body.
Output: Hello, welcome to Python

Program 2 – Function with a Single Argument

Python Program

def square(n):
    print("Square =", n * n)

square(6)
Explanation:
The function square(n) has one parameter, n. When square(6) is called, the value 6 is passed to n.

The function calculates n × n and directly displays the result. There is no return value in this example.
Output: Square = 36

Program 3 – Function with Multiple Arguments and Return

Python Program

def add(a, b):
    return a + b

x = int(input("Enter first number: "))
y = int(input("Enter second number: "))

result = add(x, y)

print("Sum =", result)
Explanation:
The function add(a, b) has two parameters. The values entered by the user are passed to the function.

The function calculates a + b and uses return to send the result back to the calling statement.

The returned value is stored in result and then displayed.
Sample Input: 10 20 Output: Sum = 30

Program 4 – Function with Argument and if Condition

Python Program

def check_even(n):
    if n % 2 == 0:
        return "Even"
    else:
        return "Odd"

n = int(input("Enter number: "))

result = check_even(n)

print(result)
Explanation:
The function receives one value through parameter n. Inside the function, an if-else statement checks the remainder when n is divided by 2.

If the remainder is zero, the function returns "Even"; otherwise it returns "Odd".

This demonstrates how a function can contain a decision-making statement and return the result.
Sample Input: 15 Output: Odd

Program 5 – Function with a Loop and Return

Python Program

def sum_n(n):
    s = 0

    for i in range(1, n + 1):
        s = s + i

    return s

n = int(input("Enter n: "))

result = sum_n(n)

print("Sum =", result)
Explanation:
The function sum_n(n) receives one argument. Inside the function, a for loop generates values from 1 to n.

The variable s acts as an accumulator and stores the running sum. After the loop finishes, return s sends the final result back to the calling statement.

For n = 5, the sum is 1 + 2 + 3 + 4 + 5 = 15.
Sample Input: 5 Output: Sum = 15

5. Important Points to Remember

  • Use def to define a user defined function.
  • A function is executed when it is called.
  • Parameters are written in the function definition.
  • Arguments are the actual values supplied during a function call.
  • A function may have no arguments, one argument or multiple arguments.
  • A function may return a value using return.
  • print() displays a value; return sends a value back to the caller.
  • A function can contain if-else statements and loops.
  • Using functions helps reduce repeated code and improves program organization.
