File Input and Output – Exhaustive Theory and Examples

1. What is File Input and Output?

File Input and Output (File I/O) means reading data from files and writing data to files using Python.

OperationMeaningDescription
Input from fileReadingTransfers stored data from an external file into the program.
Output to fileWritingStores data produced by the program in an external file.
Explanation: Files provide persistent storage, so information can remain available after a program finishes.

2. open() Function

Python uses the built-in open() function to open a file.

open("filename", "mode")
ArgumentExampleDescription
filename"data.txt"Name or path of the file.
mode"r"Specifies the required operation.
encodingencoding="utf-8"Specifies character encoding.

3. File Modes

ModeNameDescription
rReadReads an existing file. Missing file normally causes FileNotFoundError.
wWriteCreates a missing file or replaces existing contents.
aAppendPreserves existing contents and writes at the end.
xCreateCreates a new file; fails if it already exists.
r+Read + WriteReads and writes an existing file.
w+Write + ReadReads and writes, but existing contents are replaced.
a+Append + ReadReads and appends while preserving existing contents.

4. Creating a File

file = open("data.txt", "w")
file.close()
Explanation: Write mode creates data.txt if it does not exist. If it exists, its previous contents are cleared.

5. write()

file.write("text")
with open("data.txt", "w") as file:
    file.write("Hello")
    file.write("Python")
Explanation: write() writes a string. It does not automatically insert a newline.

6. Newline Character

with open("data.txt", "w") as file:
    file.write("Hello\n")
    file.write("Python")
File contents: Hello Python
Explanation: \n moves the following text to a new line.

7. writelines()

file.writelines(sequence)
lines = ["Apple\n", "Banana\n", "Orange"]
with open("data.txt", "w") as file:
    file.writelines(lines)
Explanation: writelines() writes multiple strings. It does not automatically add newline characters.

8. read()

file.read()
with open("data.txt", "r") as file:
    data = file.read()
    print(data)
Explanation: read() reads the complete remaining contents as one string.

9. read(size)

file.read(size)
with open("data.txt", "r") as file:
    data = file.read(5)
    print(data)
Explanation: The size argument limits how many characters are read from the current position.

10. readline()

file.readline()
with open("data.txt", "r") as file:
    line = file.readline()
    print(line)
Explanation: readline() reads one line from the current file position.

11. readlines()

file.readlines()
with open("data.txt", "r") as file:
    lines = file.readlines()
    print(lines)
Explanation: readlines() reads the remaining lines and returns a list of strings.

12. Reading Methods Comparison

MethodReturnsDescription
read()StringReads all remaining contents.
read(size)StringReads a limited number of characters.
readline()StringReads one line.
readlines()ListReads remaining lines as list elements.

13. File Pointer – tell()

file.tell()
with open("data.txt", "r") as file:
    print(file.tell())
    file.read(5)
    print(file.tell())
Explanation: tell() returns the current position of the file pointer.

14. File Pointer – seek()

file.seek(position)
with open("data.txt", "r") as file:
    file.read(5)
    file.seek(0)
    print(file.read(5))
Explanation: seek() moves the file pointer. seek(0) moves it to the beginning.

15. with Statement

with open("data.txt", "r") as file:
Explanation: The with statement automatically closes the file after the indented block is completed. It is the recommended approach for normal file operations.

16. close()

file = open("data.txt", "r")
data = file.read()
file.close()
Explanation: close() explicitly closes the file and releases the associated resource. With with, it is normally unnecessary.

17. Write Mode vs Append Mode

ModeEffectExplanation

aAddExisting contents remain and new data is added at the end.

19. File Encoding

open("data.txt", "r", encoding="utf-8")
Explanation: Encoding defines how characters are represented in a file. UTF-8 is a widely used encoding.

23. CSV Files

CSV means Comma-Separated Values. It is commonly used for tabular data.

Example:
Name,Age,City
Alice,20,Delhi

Python provides the built-in csv module for CSV files.

24. Writing CSV

import csv
with open("data.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerow(["Name", "Age", "City"])
    writer.writerow(["Alice", 20, "Delhi"])
Explanation: csv.writer() creates a writer and writerow() writes one row.

25. Writing Multiple CSV Rows

rows = [["Alice",20], ["Bob",21], ["Charlie",19]]
with open("data.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerows(rows)
Explanation: writerows() writes multiple rows in one operation.

26. Reading CSV

import csv
with open("data.csv", "r") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
Explanation: csv.reader() reads rows one at a time, with each row commonly represented as a list.

27. CSV Dictionary Operations

ConceptExampleDescription
DictReadercsv.DictReader(file)Reads each row as a dictionary using headings as keys.
DictWritercsv.DictWriter(file, fieldnames=fields)Writes dictionary data to CSV using specified field names.
Headerwriter.writeheader()Writes field names as the first row.

28. newline="" in CSV

open("data.csv", "w", newline="")
Explanation: newline="" allows the CSV module to manage newline characters correctly and helps avoid unwanted blank lines on some systems.

31. Important Theory Points

  • open() is used to open files.
  • r reads, w writes/replaces, a appends, and x creates.
  • w creates a missing file automatically.
  • r normally raises FileNotFoundError for a missing file.
  • write() writes a string and does not automatically add a newline.
  • writelines() writes multiple strings but does not add newlines automatically.
  • read() reads complete remaining contents.
  • readline() reads one line.
  • readlines() returns remaining lines as a list.
  • with automatically closes the file.
  • tell() returns the current file-pointer position.
  • seek() moves the file pointer.
  • CSV is useful for tabular data.
  • csv.reader() reads CSV rows and csv.writer() writes them.
  • newline="" is commonly used when writing CSV files.
  • JSON is a structured data format handled by Python's json module.
