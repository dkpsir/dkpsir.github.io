2. String Indexing

Indexing is used to access an individual character. Python uses zero-based indexing, so the first character is at index 0.

ConceptExample CodeDescription / Explanation

Exampleword = "PYTHON"; print(word[0]); print(word[-1])The output is P and N because indexing starts at 0 and -1 represents the last character.

24. Important Points for Theory Examination

  • A string is a sequence of characters.
  • Strings support indexing, negative indexing and slicing.
  • String indexes start at 0; the last character can be accessed using -1.
  • In slicing, the stop index is excluded.
  • Strings are immutable.
  • Concatenation uses + and repetition uses *.
  • in and not in perform membership testing.
  • len() returns the number of characters.
  • upper(), lower(), capitalize(), title() and swapcase() perform case-related operations.
  • strip(), lstrip() and rstrip() remove whitespace from string ends.
  • replace() returns a new string; it does not modify the original string.
  • find() returns -1 when text is absent, while index() raises an exception.
  • split() returns a list, while join() returns a string.
  • Methods beginning with is, such as isalpha() and isdigit(), generally return Boolean values.
  • Escape sequences such as \n and \t represent special characters.
  • f-strings are a concise method of string formatting.
  • Raw strings are useful when backslashes need to be treated literally.
