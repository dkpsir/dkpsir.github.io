INPUT - OUTPUT FUNCTIONS

Python Programming – Basic Concepts

1. Basic Theory

Input means accepting data from the user during program execution. In Python, the input() function is used to receive keyboard input.

Output means displaying information, calculated results, messages, or values on the screen. In Python, the print() function is used to display output.

Basic Workflow:
Input → Process / Calculation → Output

In general programs, input statements collect necessary values such as names, quantities, prices, marks, or temperatures, and output statements display the formatted results.

2. input() Function – Syntax

General Syntax
variable = input("prompt message")
variable

Stores the value entered by the user.

=

Assignment operator to store the input into memory.

input()

Built-in function that captures keyboard input.

"prompt message"

Optional text instructing the user what to enter.

Important: The value returned by input() is always a string (str). Wrap with int() or float() for numerical calculations.

4. Type Conversion with input()

Since input() produces a string, using the + operator directly performs string concatenation rather than numerical addition.

The Beginner Trap (Concatenation vs Addition):
• Without Conversion: "10" + "20" → "1020" (String concatenation)
• With Conversion: int("10") + int("20") → 30 (Arithmetic addition)

6. print() Function – Syntax

General Syntax
print(value1, value2, sep=" ", end="\n")
print()

Built-in function used to display values to standard output.

value

String, number, variable, or calculated expression.

sep=" "

String inserted between multiple arguments (default is a space).

end="\n"

String appended after the last value (default is a newline).

13. Important Points to Remember

  • input() always returns data of type string.
  • Wrap with int() for whole numbers and float() for decimals before arithmetic operations.
  • Use split() or map() to read multiple variables from a single line.
  • sep defines what appears between arguments inside print().
  • end defines what character terminates the print() statement (default is newline \n).
  • f-strings (f"{val:.2f}") provide clear numeric rounding and variable interpolation.
