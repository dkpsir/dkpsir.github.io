PART 1: OBJECT-ORIENTED PROGRAMMING FUNDAMENTALS

1. What is Object-Oriented Programming?

Object-Oriented Programming (OOP) is a programming approach in which a program is organized around objects rather than only around individual statements or functions. An object represents an entity and contains both data and the operations that can work on that data.

Python supports object-oriented programming and provides features such as classes, objects, methods, constructors, inheritance, polymorphism, encapsulation, and abstraction.

3. Class: Basic Concept

A class is a user-defined blueprint that describes the attributes and methods that objects created from it may have.

The class itself is not normally the individual entity being manipulated. Objects are created from the class.

Basic Class Syntax

class ClassName:
    # attributes
    # methods
    pass
Important: Python uses the keyword class to define a class. The class body is written using indentation, just like the body of a function or conditional statement.

PART 2: ATTRIBUTES AND METHODS

6. Attributes: Data Stored in Objects

An attribute is a variable associated with an object or class. Attributes represent the data or state of an object.

For example, a Student object may have name, roll_no, and marks as attributes.

Example: Instance Attributes

class Student:
    pass

s1 = Student()
s1.name = "Ravi"
s1.marks = 85

print(s1.name)
print(s1.marks)
Explanation:
The attributes name and marks are attached to object s1.
Output: Ravi 85
Important: Although attributes can be added directly to an object, it is generally better to initialize important instance attributes inside the class constructor using __init__().

7. Methods: Functions Inside a Class

A method is a function defined inside a class. Methods describe the behaviour or actions that objects of the class can perform.

Example

class Student:
    def display(self):
        print("Student details")

s1 = Student()
s1.display()
Explanation:
display() is a method of Student. The object s1 calls the method using the dot operator.
Output: Student details

8. The self Parameter

self represents the current object on which an instance method is operating. It allows a method to access the attributes and other methods belonging to that particular object.

Example

class Student:
    def display(self):
        print("This method belongs to:", self)

s1 = Student()
s1.display()
Important rules about self:
  • self is normally the first parameter of an instance method.
  • When calling the method, you normally do not write self explicitly.
  • Python automatically passes the calling object as the first argument.
  • The name self is a strong convention; it should be used for clarity.
Conceptual view: When you write s1.display(), Python internally supplies the object s1 to the method.

9. Understanding object.attribute

The dot operator . is used to access attributes and methods belonging to an object.

ExpressionMeaning
s1.nameAccesses the name attribute of object s1.
s1.marksAccesses the marks attribute of object s1.
s1.display()Calls the display method using s1.

10. Constructor: __init__()

The special method __init__() is commonly called the constructor in Python teaching. It is automatically invoked when an object is initialized through a class call.

It is mainly used to initialize instance attributes with starting values.

Example

class Student:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

s1 = Student("Ravi", 85)

print(s1.name)
print(s1.marks)
Explanation:
When Student("Ravi", 85) is executed, Python creates the object and calls __init__() to initialize its attributes.
Output: Ravi 85

PART 3: TYPES OF ATTRIBUTES AND METHODS

13. Instance Attributes

An instance attribute belongs to a particular object. Different objects of the same class can have different values for the same instance attribute.

Example

class Student:
    def __init__(self, name):
        self.name = name

s1 = Student("Ravi")
s2 = Student("Anita")

print(s1.name)
print(s2.name)
Key point: s1.name and s2.name are separate instance attributes stored for different objects.

14. Class Attributes

A class attribute is associated with the class itself and is shared by instances unless an instance creates an attribute with the same name.

Example

class Student:
    college = "ABC College"

s1 = Student()
s2 = Student()

print(s1.college)
print(s2.college)
Explanation:
The attribute college is defined inside the class rather than inside __init__(). Both objects can access it.
Output: ABC College ABC College

15. Instance Method

An instance method works with an individual object and normally has self as its first parameter.

class Student:
    def __init__(self, name):
        self.name = name

    def display(self):
        print("Name:", self.name)

s1 = Student("Ravi")
s1.display()

16. Class Method

A class method receives the class itself as its first argument, conventionally named cls. It is created using the @classmethod decorator.

Example

class Student:
    college = "ABC College"

    @classmethod
    def show_college(cls):
        print(cls.college)

Student.show_college()
Explanation:
cls refers to the class. A class method can be called using the class itself.
Output: ABC College

17. Static Method

A static method does not automatically receive self or cls. It is defined using @staticmethod.

Example

class Calculator:
    @staticmethod
    def add(a, b):
        return a + b

print(Calculator.add(10, 20))
Use: A static method is useful when a function logically belongs to a class but does not need object or class data.

PART 4: ENCAPSULATION AND ACCESS CONTROL

19. Encapsulation

Encapsulation means combining data and the methods that operate on that data into a single unit, usually a class. It also supports controlled access to internal data.

Data / Attributes
+
Methods
→
Class
Python note: Python does not enforce access control in exactly the same way as some languages. Naming conventions such as _name and name mangling with __name are commonly used to indicate or restrict direct access.

20. Public Attributes

A normal attribute such as self.name is conventionally public and can be accessed directly through the object.
class Student:
    def __init__(self, name):
        self.name = name

s1 = Student("Ravi")
print(s1.name)

21. Protected-Style Attribute: Single Underscore

An attribute beginning with one underscore, such as _marks, is a convention indicating that the attribute is intended for internal or subclass use. It is not true access restriction.

class Student:
    def __init__(self):
        self._marks = 85

s1 = Student()
print(s1._marks)
Remember: A single underscore is mainly a naming convention in Python; it does not make the attribute completely inaccessible.

22. Private-Style Attribute: Double Underscore

An attribute beginning with two underscores, such as __marks, triggers Python's name mangling. This helps avoid accidental name conflicts and discourages direct external access.

class Student:
    def __init__(self):
        self.__marks = 85

    def display(self):
        print(self.__marks)

s1 = Student()
s1.display()
The method can access __marks internally. Python transforms the internal name using name mangling.
PART 5: INHERITANCE

23. What is Inheritance?

Inheritance allows a new class to acquire attributes and methods from an existing class. The existing class is commonly called the parent/base/superclass, and the new class is called the child/derived/subclass.

Parent / Base Class
↓
Child / Derived Class
Purpose: Reuse existing functionality and extend or specialize it in a new class.

24. Single Inheritance

Example

class Animal:
    def speak(self):
        print("Animal sound")

class Dog(Animal):
    pass

d = Dog()
d.speak()
Explanation:
Dog inherits from Animal. Therefore a Dog object can use the inherited speak() method.
Output: Animal sound

25. Inheritance with Child-Specific Method

class Animal:
    def speak(self):
        print("Animal sound")

class Dog(Animal):
    def bark(self):
        print("Dog barks")

d = Dog()
d.speak()
d.bark()
The child class can use inherited methods and can also define its own additional methods.

26. Method Overriding

Method overriding occurs when a child class defines a method with the same name as a method in its parent class. The child version is used for objects of the child class.

Example

class Animal:
    def speak(self):
        print("Animal sound")

class Dog(Animal):
    def speak(self):
        print("Bark")

d = Dog()
d.speak()
Explanation:
Dog provides its own implementation of speak(), so the Dog version is called.
Output: Bark

27. The super() Function

super() is used to access methods or initialization behavior from a parent class.

class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed

d = Dog("Tommy", "Labrador")
print(d.name)
print(d.breed)
Why use super()? It allows the child class to reuse parent-class functionality instead of duplicating the same initialization code.

29. Multiple Inheritance

class A:
    def method_a(self):
        print("A")

class B:
    def method_b(self):
        print("B")

class C(A, B):
    pass

obj = C()
obj.method_a()
obj.method_b()
Class C inherits from both A and B. Therefore an object of C can access methods supplied by both parent classes.

30. Multilevel Inheritance

class Grandparent:
    def show1(self):
        print("Grandparent")

class Parent(Grandparent):
    def show2(self):
        print("Parent")

class Child(Parent):
    def show3(self):
        print("Child")

c = Child()
c.show1()
c.show2()
c.show3()
PART 6: POLYMORPHISM AND ABSTRACTION

31. What is Polymorphism?

Polymorphism means "many forms." In OOP, the same method name or operation can produce different behavior depending on the object involved.

Example

class Dog:
    def sound(self):
        print("Bark")

class Cat:
    def sound(self):
        print("Meow")

for animal in [Dog(), Cat()]:
    animal.sound()
Explanation:
The same method call animal.sound() produces different behavior for Dog and Cat.
Output: Bark Meow

32. Duck Typing

Python often follows a form of polymorphism called duck typing: if an object provides the required method, the code can use that method without requiring the object's exact class to be checked first.

class Printer:
    def show(self):
        print("Printing")

class Display:
    def show(self):
        print("Displaying")

def execute(obj):
    obj.show()

execute(Printer())
execute(Display())
The function only requires that the supplied object provide a show() method.

33. Abstraction

Abstraction means focusing on essential behavior while hiding implementation details that the user does not need to know.

Python provides the abc module and abstract base classes for formal abstraction.

Example Using Abstract Base Class

from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

class Circle(Shape):
    def area(self):
        return 3.14 * 5 * 5

c = Circle()
print(c.area())
A subclass must provide an implementation of an abstract method before it can normally be instantiated.

35. Special Methods / Dunder Methods

Python has special methods whose names usually begin and end with double underscores. They are often called dunder methods (double underscore methods).

MethodCommon Purpose

__repr__()Define a representation useful for developers/debugging.

36. The __str__() Method

Example

class Student:
    def __init__(self, name):
        self.name = name

    def __str__(self):
        return "Student: " + self.name

s1 = Student("Ravi")
print(s1)
Explanation:
When the object is passed to print(), Python can use __str__() to obtain a readable representation.
Output: Student: Ravi

37. Object Identity and Equality

Two objects can contain equal data but still be different objects. Python provides is for identity comparison and == for equality comparison.

class Student:
    def __init__(self, name):
        self.name = name

s1 = Student("Ravi")
s2 = Student("Ravi")

print(s1 == s2)
print(s1 is s2)
Important: Unless equality behavior is customized, two separately created objects are not automatically considered equal merely because their attributes contain the same values.

40. Complete Example: Multiple Objects

class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary

    def display(self):
        print(self.name, self.salary)

e1 = Employee("Ravi", 30000)
e2 = Employee("Anita", 40000)

e1.display()
e2.display()

The class is written once but three separate objects are created. Each object maintains its own instance attributes.

41. Complete Example: Inheritance + Overriding

class Employee:
    def work(self):
        print("Employee is working")

class Engineer(Employee):
    def work(self):
        print("Engineer is designing")

class Teacher(Employee):
    def work(self):
        print("Teacher is teaching")

e = Engineer()
t = Teacher()

e.work()
t.work()
The same method name work() has different implementations in the derived classes. This demonstrates inheritance and polymorphism through method overriding.

42. Complete Example: Encapsulation with Methods

class BankAccount:
    def __init__(self, balance):
        self.__balance = balance

    def deposit(self, amount):
        self.__balance += amount

    def show_balance(self):
        print("Balance:", self.__balance)

account = BankAccount(1000)
account.deposit(500)
account.show_balance()
Output: Balance: 1500
The balance is maintained internally and modified through a method rather than directly in normal use.
