PART 1: MATPLOTLIB CONCEPTS

1. Basic Theory: What is Matplotlib?

Matplotlib is the core plotting library in Python. Its pyplot module provides a MATLAB-like interface for generating static, 2D charts like line graphs, scatter plots, and histograms.

Example 1: Basic Line Plot

import matplotlib.pyplot as plt
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]
plt.plot(x, y)
plt.show()
Explanation:
plt.plot() connects data points with lines. plt.show() renders and displays the graphical window.

Example 2: Adding Markers

plt.plot(x, y, marker='o', color='red')
plt.show()
Explanation:
Customizes the plot line to be red and places a circle marker ('o') at every data point.

Example 3: Figure Size

plt.figure(figsize=(8, 4))
plt.plot(x, y)
plt.show()
Explanation:
plt.figure(figsize=(width, height)) creates a customized blank canvas before drawing.

2. Plot Formatting & Labels

Good visualizations require context. Matplotlib provides functions to add titles, axis labels, legends, and gridlines.

Example 1: Titles and Labels

plt.plot([1, 2, 3], [5, 7, 4])
plt.title("Sensor Readings")
plt.xlabel("Time (s)")
plt.ylabel("Value")
plt.show()
Explanation:
Applies descriptive text to the top, x-axis, and y-axis of the chart.

Example 2: Multiple Lines & Legend

plt.plot([1, 2], [10, 20], label="Hot")
plt.plot([1, 2], [5, 10], label="Cold")
plt.legend()
plt.show()
Explanation:
Calling plot() multiple times overlays them. plt.legend() displays a key using the label arguments.

Example 3: Grids & Layout

plt.plot([1, 2, 3], [5, 7, 4])
plt.grid(True)
plt.tight_layout()
plt.show()
Explanation:
plt.grid(True) adds background guide lines. plt.tight_layout() prevents labels from getting cut off at the edges.
PART 2: SEABORN CONCEPTS

3. Basic Theory: What is Seaborn?

Seaborn is a statistical data visualization library built on top of Matplotlib. It integrates deeply with Pandas DataFrames and provides high-level commands for complex and aesthetically pleasing plots (like heatmaps and automated bar charts).

Example 1: Seaborn Bar Plot

import seaborn as sns
import pandas as pd
df = pd.DataFrame({"Test": ["T1", "T2"], "Val": [50, 80]})
sns.barplot(data=df, x="Test", y="Val")
plt.show()
Explanation:
sns.barplot() automatically extracts columns from a DataFrame and generates a colored bar chart. (Still requires plt.show() to display).

Example 2: Seaborn Heatmap

df2 = pd.DataFrame({"A": [1, 2], "B": [2, 4]})
sns.heatmap(df2, annot=True, cmap="coolwarm")
plt.show()
Explanation:
Generates a color-coded grid. annot=True overlays the numerical values. cmap sets the color theme.

Example 3: Scatter Plot

df3 = pd.DataFrame({"X": [1, 2, 3], "Y": [3, 1, 4]})
sns.scatterplot(data=df3, x="X", y="Y")
plt.show()
Explanation:
Plots points without connecting lines, useful for identifying relationships between variables.

Seaborn: Correlation Matrix Heatmap 
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
df = pd.DataFrame({"Temp": [80, 85, 90], "Heat": [6, 7, 8]})
sns.heatmap(df.corr(), annot=True, vmin=-1, vmax=1, cmap="coolwarm")
plt.show()
 First calculates statistical correlation using df.corr(), then maps those percentages to a color scale using vmin and vmax.
Matplotlib: Saving a Plot to Image 
import matplotlib.pyplot as plt
plt.plot([1, 2], [10, 20])
plt.title("My Graph")
plt.savefig("my_graph.png", dpi=300)
# plt.show() is omitted
 Instead of displaying the plot on the screen with show(), savefig() exports the canvas as a high-resolution PNG image file.
Matplotlib: Subplots (Multiple Charts) 
import matplotlib.pyplot as plt
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))
ax1.plot([1, 2], [5, 10])
ax2.bar(['A', 'B'], [20, 30])
plt.show()
 Creates a side-by-side layout (1 row, 2 columns). ax1 and ax2 act as individual plotting areas within a single window.
