Error Handling – Concepts and Examples

1. What is Error Handling?

Error handling is the process of detecting and managing errors that occur while a program is running. Python provides exception handling so that a program can respond to runtime problems in a controlled manner.

TermMeaningDescription
ErrorProblem in a programA condition that prevents the program from producing the intended result.
ExceptionRuntime eventAn event that interrupts the normal flow of execution.
Exception HandlingManaging exceptionsUsing Python statements to detect and handle exceptions.
Important: Error handling is especially useful when input or runtime conditions cannot be guaranteed to be valid.

4. try Block

The try block contains statements that may generate an exception.

try: statements_that_may_cause_error
Python first attempts to execute the statements inside the try block.

5. except Block

The except block contains statements used to handle a matching exception.

try: number = int(input("Enter an integer: ")) except ValueError: print("Please enter a valid integer.")
If the input cannot be converted to an integer, ValueError is raised and the except block executes.

6. Multiple except Blocks

try: a = int(input("Enter a: ")) b = int(input("Enter b: ")) print(a / b) except ValueError: print("Enter numbers only.") except ZeroDivisionError: print("Division by zero is not allowed.")
Different exception types can have different handling statements.

7. Exception Object using as

An exception object can be stored in a variable using as.

try: number = int("abc") except ValueError as e: print("Error:", e)
Error: invalid literal for int() with base 10: 'abc'
Here, e refers to the exception object and can be used to display its message.

8. else Block

The else block executes only when no exception occurs in the try block.

try: number = int(input("Enter an integer: ")) except ValueError: print("Invalid input.") else: print("Valid integer:", number)

9. finally Block

The finally block is used for statements that should normally execute whether an exception occurs or not.

try: number = int(input("Enter a number: ")) except ValueError: print("Invalid input.") finally: print("Execution completed.")
It is commonly used for cleanup or final status messages.

10. Complete try–except–else–finally Structure

12. raise Statement

The raise statement explicitly generates an exception when a programmer-defined condition is not satisfied.

raise ValueError("Invalid value")
age = int(input("Enter age: ")) if age < 0: raise ValueError("Age cannot be negative.") print("Age:", age)
Remember: raise generates the exception; except handles it.

13. Custom / User-Defined Exceptions

A programmer can create an application-specific exception by defining a class derived from Exception.

class TemperatureError(Exception): pass
The custom exception name should describe the condition it represents.

14. Raising and Handling a Custom Exception

class TemperatureError(Exception): pass try: temperature = 120 if temperature > 100: raise TemperatureError("Temperature is too high.") except TemperatureError as e: print("Temperature Error:", e)
Temperature Error: Temperature is too high.

16. Example for Introducing Error Handling in Lab

The following Student Marks and Average program is used only as a simple classroom example to introduce try, except, raise, else and finally. It is not the Experiment 7 mechanical program.

# Program: Student Marks and Average

try:
    n = int(input("Enter number of subjects: "))

    if n <= 0:
        raise ValueError("Number of subjects must be positive")

    total = 0

    for i in range(n):
        marks = float(input(f"Enter marks for subject {i + 1}: "))

        if marks < 0 or marks > 100:
            raise ValueError("Marks must be between 0 and 100")

        total += marks

except ValueError as e:
    print("Error:", e)

except ZeroDivisionError:
    print("Error: Cannot calculate average with zero subjects.")

else:
    average = total / n
    print("Total Marks:", total)
    print("Average Marks:", average)

finally:
    print("Program execution completed.")

22. Important Theory Points

  • Exception handling manages runtime problems in a controlled manner.
  • try contains statements that may cause an exception.
  • except handles a matching exception.
  • Multiple except blocks can be used for different exception types.
  • as e stores the exception object in a variable.
  • else executes only when no exception occurs in try.
  • finally is used for actions that should normally execute regardless of an exception.
  • raise explicitly generates an exception.
  • ValueError, TypeError, ZeroDivisionError, IndexError and FileNotFoundError are common built-in exceptions.
  • Custom exceptions can be created by inheriting from Exception.
  • Specific exception handling is generally clearer than unnecessarily broad handling.
  • Exception handling does not automatically correct logical errors.
  • Input validation and exception handling can be used together.
