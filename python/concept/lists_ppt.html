1. Basic Theory – Lists

A list is an ordered collection of items in Python. A list can contain multiple values in a single variable.

Creating a List
list_name = [item1, item2, item3, ...]

Lists are written using square brackets [ ]. List elements are accessed using their index, starting from 0.

Example

marks = [75, 82, 68, 91]
Index positions:
marks[0] → 75
marks[1] → 82
marks[2] → 68
marks[3] → 91

2. Basic Theory – Tuples

A tuple is also an ordered collection of items. Like a list, tuple elements are accessed using indexes.

Creating a Tuple
tuple_name = (item1, item2, item3, ...)

Tuples are generally written using parentheses ( ).

Important: A tuple is immutable. After a tuple is created, its elements cannot be changed, added or removed.

4. Creating and Accessing Elements

List

numbers = [10, 20, 30, 40]

print(numbers[0])
print(numbers[2])
print(numbers[-1])

Tuple

numbers = (10, 20, 30, 40)

print(numbers[0])
print(numbers[2])
print(numbers[-1])
Both lists and tuples support indexing. Positive indexing starts from 0, while negative indexing starts from the last element using -1.

5. Modifying a List

Python Program

numbers = [10, 20, 30]

numbers[1] = 25

print(numbers)
Explanation:
Lists are mutable. Therefore, the element at index 1 can be changed from 20 to 25.
Output: [10, 25, 30]

6. Tuple Cannot Be Modified

Example

numbers = (10, 20, 30)

numbers[1] = 25
Explanation:
A tuple is immutable. Therefore, trying to change an existing tuple element produces an error.

The important concept is not the exact error message, but the fact that tuple elements cannot be modified.

8. Frequently Used General Programs

Program 1 – Find the Sum of List Elements

Python Program

numbers = [10, 20, 30, 40, 50]

s = 0

for x in numbers:
    s = s + x

print("Sum =", s)
Explanation:
The for loop visits each element of the list one by one. The variable s stores the running total.

10 + 20 + 30 + 40 + 50 = 150.
Output: Sum = 150

Program 2 – Find the Largest Element in a List

Python Program

numbers = [25, 12, 48, 7, 36]

largest = numbers[0]

for x in numbers:
    if x > largest:
        largest = x

print("Largest =", largest)
Explanation:
Initially, the first element is assumed to be the largest. The loop compares every element with the current largest value. Whenever a larger value is found, largest is updated.
Output: Largest = 48

Program 3 – Count Even and Odd Numbers in a List

Python Program

numbers = [12, 7, 18, 5, 20, 9]

even = 0
odd = 0

for x in numbers:
    if x % 2 == 0:
        even = even + 1
    else:
        odd = odd + 1

print("Even =", even)
print("Odd =", odd)
Explanation:
The loop checks each element. If the remainder after division by 2 is zero, the even counter is increased; otherwise, the odd counter is increased.
Output: Even = 3 Odd = 3

Program 4 – Find the Average of Tuple Elements

Python Program

marks = (70, 80, 65, 85, 90)

s = 0

for x in marks:
    s = s + x

average = s / len(marks)

print("Average =", average)
Explanation:
The loop calculates the total of all tuple elements. len(marks) gives the number of elements. The average is calculated as:

Average = Sum / Number of elements.
Output: Average = 78.0

Program 5 – Search for an Element

Python Program

numbers = [10, 25, 30, 45, 50]

key = int(input("Enter number: "))

found = False

for x in numbers:
    if x == key:
        found = True
        break

if found:
    print("Found")
else:
    print("Not Found")
Explanation:
The program checks each list element against the value entered by the user. If a matching value is found, found becomes True and break stops the loop.

For input 30, the value is present in the list.
Output: Found

9. Important Points to Remember

  • A list is an ordered and mutable collection.
  • A tuple is an ordered and immutable collection.
  • Both lists and tuples use indexing starting from 0.
  • Lists are written using square brackets [ ].
  • Tuples are commonly written using parentheses ( ).
  • Elements of a list can be modified.
  • Elements of a tuple cannot be modified.
  • Both can be processed using a for loop.
  • len() can be used to find the number of elements.
  • Use a list when the collection may need to change; use a tuple when the data should remain fixed.
