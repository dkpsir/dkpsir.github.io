PART 1: NUMPY CONCEPTS

1. Basic Theory: What is NumPy?

NumPy stands for Numerical Python. It provides the N-dimensional array (ndarray) object for fast vector operations.

Example 1

import numpy as np
arr = np.array([10, 20, 30])
print(arr)
Explanation:
Imports the library and creates a standard 1D array.
Output: [10 20 30]

Example 2

print(type(arr))
Explanation:
Confirms the object is a NumPy ndarray.
Output:

Example 3

arr2d = np.array([[1, 2], [3, 4]])
print(arr2d)
Explanation:
Creates a 2D array by nesting lists.
Output: [[1 2] [3 4]]

2. Creating Arrays

NumPy provides built-in functions to generate arrays initialized with zeros, ones, or sequences.

Example 1

z = np.zeros((2, 3))
print(z)
Explanation:
Creates a 2x3 matrix filled entirely with zeros.
Output: [[0. 0. 0.] [0. 0. 0.]]

Example 2

o = np.ones(4)
print(o)
Explanation:
Creates a 1D array of length 4 filled with ones.
Output: [1. 1. 1. 1.]

Example 3

seq = np.arange(1, 10, 2)
print(seq)
Explanation:
Creates an array from 1 up to 10 with a step size of 2.
Output: [1 3 5 7 9]

3. Array Properties (Attributes)

Every ndarray has attributes that describe its size, shape, and data type.

Example 1

arr = np.array([[1, 2, 3], [4, 5, 6]])
print(arr.shape)
Explanation:
Returns the dimensions (rows, columns).
Output: (2, 3)

Example 2

print(arr.ndim)
Explanation:
Returns the number of dimensions (2D in this case).
Output: 2

Example 3

print(arr.size)
print(arr.dtype)
Explanation:
size returns total elements; dtype returns the data type.
Output: 6 int64

4. Accessing Array Elements

Use brackets to access individual elements or slice arrays.

Example 1

arr = np.array([10, 20, 30, 40])
print(arr[1])
Explanation:
Accesses the element at index 1 (second element).
Output: 20

Example 2

arr2d = np.array([[1, 2], [3, 4]])
print(arr2d[1, 0])
Explanation:
Accesses row 1, column 0 in a 2D array.
Output: 3

Example 3

print(arr[1:4])
Explanation:
Slices the 1D array from index 1 up to (but excluding) 4.
Output: [20 30 40]

5. Boolean Masking & Filtering

You can filter arrays by passing conditional statements inside the index brackets.

Example 1

arr = np.array([5, 10, 15, 20])
print(arr > 12)
Explanation:
Generates a boolean mask (True/False) for the condition.
Output: [False False True True]

Example 2

filtered = arr[arr > 12]
print(filtered)
Explanation:
Applies the boolean mask to extract only matching elements.
Output: [15 20]

Example 3

multi = arr[(arr > 5) & (arr < 20)]
print(multi)
Explanation:
Filters using multiple conditions (AND logic).
Output: [10 15]

6. Combining & Splitting Arrays

Arrays can be joined together (concatenated) or split apart.

Example 1

a = np.array([1, 2])
b = np.array([3, 4])
print(np.concatenate((a, b)))
Explanation:
Joins two 1D arrays end-to-end.
Output: [1 2 3 4]

Example 2

print(np.vstack((a, b)))
Explanation:
Stacks arrays vertically, creating a 2D array.
Output: [[1 2] [3 4]]

Example 3

arr = np.array([1, 2, 3, 4])
print(np.split(arr, 2))
Explanation:
Splits a single array into 2 equal sub-arrays.
Output: [array([1, 2]), array([3, 4])]

7. Random Number Generation

The np.random module provides fast random array generation.

Example 1

r = np.random.rand(2)
print(r)
Explanation:
Generates an array of 2 random floats between 0 and 1.
Output: [0.5488135 0.71518937]

Example 2

ri = np.random.randint(1, 10, 3)
print(ri)
Explanation:
Generates 3 random integers between 1 and 9.
Output: [7 1 3]

Example 3

ch = np.random.choice([10, 20, 30], 2)
print(ch)
Explanation:
Randomly selects 2 items from the given list.
Output: [20 10]

8. Array Math & Broadcasting

Operations apply element-by-element automatically. Broadcasting allows math across different shapes.

Example 1

a = np.array([1, 2, 3])
print(a + 5)
Explanation:
Adds 5 to every element (broadcasting).
Output: [6 7 8]

Example 2

b = np.array([10, 10, 10])
print(a * b)
Explanation:
Multiplies two arrays of the same size element-by-element.
Output: [10 20 30]

Example 3

print(a ** 2)
Explanation:
Squares every element in the array.
Output: [1 4 9]

9. Useful Array Operations

NumPy includes highly optimized statistical and mathematical methods.

Example 1

arr = np.array([2, 4, 6, 8])
print(np.sum(arr))
Explanation:
Calculates the sum of all elements.
Output: 20

Example 2

print(np.max(arr))
Explanation:
Finds the maximum value in the array.
Output: 8

Example 3

print(np.mean(arr))
Explanation:
Calculates the mathematical average.
Output: 5.0
PART 2: PANDAS CONCEPTS

1. Basic Theory: What is Pandas?

Pandas provides two main structures: Series (1D list-like) and DataFrame (2D table-like).

Example 1

import pandas as pd
s = pd.Series([10, 20, 30])
print(s)
Explanation:
Creates a 1-dimensional Pandas Series.
Output: 0 10 1 20 2 30 dtype: int64

Example 2

df = pd.DataFrame({'A': [1, 2]})
print(df)
Explanation:
Creates a minimal DataFrame from a dictionary.
Output: A 0 1 1 2

Example 3

print(type(df))
Explanation:
Checks the data structure type.
Output:

2. Creating DataFrames

DataFrames can be built manually using Python dictionaries or lists.

Example 1

data = {'Name': ['A', 'B'], 'Age': [20, 25]}
df = pd.DataFrame(data)
print(df)
Explanation:
Creates a DataFrame where keys are columns.
Output: Name Age 0 A 20 1 B 25

Example 2

data = [[1, 'A'], [2, 'B']]
df = pd.DataFrame(data, columns=['ID', 'Cat'])
print(df)
Explanation:
Creates a DataFrame from a list of lists.
Output: ID Cat 0 1 A 1 2 B

Example 3

df = pd.DataFrame({'A': [1]}, index=['Row1'])
print(df)
Explanation:
Creates a DataFrame with custom row index labels.
Output: A Row1 1

3. DataFrame Properties & Inspection

Quick methods to inspect structure and statistics of a DataFrame.

Example 1

df = pd.DataFrame({'Val': [10, 20, 30, 40]})
print(df.head(2))
Explanation:
Returns only the first 2 rows of the data.
Output: Val 0 10 1 20

Example 2

print(df.shape)
Explanation:
Returns dimensions (rows, cols).
Output: (4, 1)

Example 3

print(df.describe())
Explanation:
Provides a statistical summary of numeric columns.
Output: Val count 4.000000 mean 25.000000 std 12.909944 min 10.000000 max 40.000000

4. Accessing Data

Select columns via brackets, and rows via loc[] (label) or iloc[] (index).

Example 1

df = pd.DataFrame({'A': [10, 20], 'B': [30, 40]})
print(df['A'])
Explanation:
Selects a single column, returning a Series.
Output: 0 10 1 20 Name: A, dtype: int64

Example 2

print(df.loc[0])
Explanation:
Selects row index '0' by label name.
Output: A 10 B 30 Name: 0, dtype: int64

Example 3

print(df.iloc[1, 0])
Explanation:
Selects specific value at row 1, col 0 numerically.
Output: 20

5. Merging, Joining, and Concatenating

Combine multiple datasets based on rows or matching columns.

Example 1

df1 = pd.DataFrame({'A': [1]})
df2 = pd.DataFrame({'A': [2]})
print(pd.concat([df1, df2], ignore_index=True))
Explanation:
Stacks DataFrames on top of each other.
Output: A 0 1 1 2

Example 2

d1 = pd.DataFrame({'id': [1], 'v1': ['A']})
d2 = pd.DataFrame({'id': [1], 'v2': ['B']})
print(pd.merge(d1, d2, on='id'))
Explanation:
Inner join on 'id' column.
Output: id v1 v2 0 1 A B

Example 3

print(pd.merge(d1, d2, how='left'))
Explanation:
Performs a Left Join keeping all rows from left table.
Output: id v1 v2 0 1 A B

6. Applying Functions (Apply)

Transform data by applying custom functions to rows or columns.

Example 1

df = pd.DataFrame({'Val': [10, 20]})
df['Double'] = df['Val'].apply(lambda x: x*2)
print(df)
Explanation:
Multiplies each value by 2 using a lambda function.
Output: Val Double 0 10 20 1 20 40

Example 2

df = pd.DataFrame({'Name': ['ali', 'sam']})
df['Name'] = df['Name'].str.upper()
print(df)
Explanation:
Uses built-in string methods across a column.
Output: Name 0 ALI 1 SAM

Example 3

print(df['Name'].apply(len))
Explanation:
Applies standard python len() function.
Output: 0 3 1 3 Name: Name, dtype: int64

7. Pivot Tables

Reshape and aggregate data simultaneously.

Example 1

df = pd.DataFrame({'G': ['A', 'A', 'B'], 'V': [1, 3, 5]})
print(df.pivot_table(index='G', values='V'))
Explanation:
Defaults to calculating the mean for each group.
Output: V G A 2.0 B 5.0

Example 2

print(df.pivot_table(index='G', aggfunc='sum'))
Explanation:
Aggregates values by summing them up instead.
Output: V G A 4 B 5

Example 3

print(df.pivot_table(columns='G', values='V'))
Explanation:
Pivots 'G' values into distinct columns.
Output: G A B V 2.0 5.0

8. Handling Datetime

Pandas has deep support for converting strings and parsing dates.

Example 1

df = pd.DataFrame({'D': ['2023-01-01']})
df['D'] = pd.to_datetime(df['D'])
print(df['D'].dtype)
Explanation:
Converts string column to datetime format.
Output: datetime64[ns]

Example 2

print(df['D'].dt.year)
Explanation:
Extracts the year component.
Output: 0 2023 Name: D, dtype: int64

Example 3

print(df['D'].dt.month_name())
Explanation:
Extracts the full name of the month.
Output: 0 January Name: D, dtype: object

9. Handling Missing Data

Identify and deal with NaN (Not a Number) values in your dataset.

Example 1

df = pd.DataFrame({'A': [1, None, 3]})
print(df.isna())
Explanation:
Returns a boolean DataFrame highlighting missing values.
Output: A 0 False 1 True 2 False

Example 2

print(df.dropna())
Explanation:
Removes any row containing a missing value.
Output: A 0 1.0 2 3.0

Example 3

print(df.fillna(0))
Explanation:
Replaces missing values with a specified number (0).
Output: A 0 1.0 1 0.0 2 3.0

10. Aggregation & Grouping

Group data by category to calculate specific metrics per group.

Example 1

df = pd.DataFrame({'Cat': ['X','X','Y'], 'V': [1,2,3]})
print(df.groupby('Cat').sum())
Explanation:
Groups by 'Cat' and calculates the sum.
Output: V Cat X 3 Y 3

Example 2

print(df.groupby('Cat').mean())
Explanation:
Groups by 'Cat' and calculates the average.
Output: V Cat X 1.5 Y 3.0

Example 3

print(df.groupby('Cat')['V'].agg(['min','max']))
Explanation:
Calculates multiple aggregations simultaneously.
Output: min max Cat X 1 2 Y 3 3
