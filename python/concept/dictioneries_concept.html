1. Basic Theory

A dictionary is a collection of data stored in key-value pairs. Each key is associated with a corresponding value.

Basic idea:
Key → Value

Dictionaries are useful when data needs to be stored and accessed using a meaningful key instead of a numerical index.

Creating a Dictionary
dictionary_name = {key1: value1, key2: value2, ...}

Dictionaries are written using curly braces { }. Each key and value are separated by a colon :, and pairs are separated by commas.

2. Key and Value

Example

student = {
    "name": "Ravi",
    "age": 20,
    "branch": "CSE"
}
Explanation:
"name" → key; "Ravi" → value
"age" → key; 20 → value
"branch" → key; "CSE" → value.

The key is used to access its corresponding value.

3. Heterogeneous Values

Example

student = {
    "name": "Anil",
    "age": 20,
    "cgpa": 8.6,
    "passed": True
}
Explanation:
Dictionary values can belong to different data types. In this example, the values are a string, integer, float and Boolean.

3. Accessing Dictionary Values

Python Program

student = {
    "name": "Ravi",
    "age": 20,
    "branch": "CSE"
}

print(student["name"])
print(student["age"])
Explanation:
Dictionary values are accessed using their keys.

student["name"] gives the value associated with "name".
student["age"] gives the value associated with "age".
Output: Ravi 20

4. Adding and Modifying Dictionary Items

Python Program

student = {
    "name": "Ravi",
    "age": 20
}

student["age"] = 21
student["branch"] = "CSE"

print(student)
Explanation:
If the key already exists, assigning a new value modifies the existing value. If the key does not exist, a new key-value pair is added.
Output: {'name': 'Ravi', 'age': 21, 'branch': 'CSE'}

5. Accessing Both Key and Value

Python Program

student = {
    "name": "Anil",
    "roll": 101,
    "branch": "CSE",
    "age": 20
}

for key, value in student.items():
    print(key, ":", value)
Explanation:
The items() method returns both the key and its corresponding value for each dictionary item. The for loop assigns them to the variables key and value.
Output: name : Anil roll : 101 branch : CSE age : 20

8. Looping Through a Dictionary

Python Program

student = {
    "name": "Ravi",
    "age": 20,
    "branch": "CSE"
}

for key in student:
    print(key, student[key])
Explanation:
The for loop goes through dictionary keys one by one. student[key] gives the value associated with the current key.
Output: name Ravi age 20 branch CSE

9. Frequently Used General Programs

Program 1 – Store and Display Student Details

Python Program

student = {
    "name": "Anil",
    "roll": 101,
    "branch": "CSE",
    "age": 20
}

print("Name:", student["name"])
print("Roll:", student["roll"])
print("Branch:", student["branch"])
print("Age:", student["age"])
Explanation:
The dictionary stores related student details using meaningful keys. Each value is accessed through its corresponding key.
Output: Name: Anil Roll: 101 Branch: CSE Age: 20

Program 2 – Calculate Total and Average Marks

Python Program

marks = {
    "Maths": 80,
    "Physics": 75,
    "Python": 90
}

total = 0

for subject in marks:
    total = total + marks[subject]

average = total / len(marks)

print("Total =", total)
print("Average =", average)
Explanation:
The subject names are keys and the marks are values. The loop adds each mark to total. Then the total is divided by the number of subjects.
Output: Total = 245 Average = 81.66666666666667

Program 3 – Find the Highest Mark

Python Program

marks = {
    "Maths": 80,
    "Physics": 75,
    "Python": 90
}

highest = 0
subject = ""

for name in marks:
    if marks[name] > highest:
        highest = marks[name]
        subject = name

print("Highest mark =", highest)
print("Subject =", subject)
Explanation:
highest stores the largest mark found so far. Each current mark is compared with it. When a larger value is found, both highest and subject are updated.
Output: Highest mark = 90 Subject = Python

Program 4 – Count Values Greater Than a Given Number

Python Program

marks = {
    "A": 72,
    "B": 85,
    "C": 64,
    "D": 91
}

count = 0

for name in marks:
    if marks[name] > 75:
        count = count + 1

print("Count =", count)
Explanation:
The loop checks each dictionary value. If the value is greater than 75, the counter is increased. Here, 85 and 91 satisfy the condition.
Output: Count = 2

Program 5 – Search for a Key

Python Program

student = {
    "name": "Ravi",
    "age": 20,
    "branch": "CSE"
}

key = input("Enter key: ")

if key in student:
    print("Key Found")
    print("Value =", student[key])
else:
    print("Key Not Found")
Explanation:
The in operator checks whether the entered key exists. If it exists, its corresponding value is accessed using student[key].
Sample Input: age Output: Key Found Value = 20

get() with and without a Default Value

Example

student = {"name": "Anil", "age": 20}

print(student.get("age"))
print(student.get("city", "Not Available"))
Explanation:
get("age") returns the value of an existing key. When a key may not exist, a default value can be supplied. Here, "city" is absent, so "Not Available" is returned.

11. Important Points to Remember

  • A dictionary stores data as key-value pairs.
  • Dictionaries use curly braces { }.
  • Values are accessed using their keys.
  • Dictionary keys must be unique.
  • Dictionaries are mutable.
  • An existing value can be changed by assigning a new value to its key.
  • A new key-value pair is created when a new key is assigned.
  • len() gives the number of key-value pairs.
  • The in operator checks whether a key exists.
  • A for loop can process dictionary keys and values.
  • A dictionary item is one complete key-value pair.
  • Dictionary values can be heterogeneous, meaning they can have different data types.
  • del, pop(), popitem() and clear() are different ways of removing dictionary data.
  • get() can return a default value when a key is not available.
