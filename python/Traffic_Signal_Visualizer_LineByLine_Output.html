Traffic SignalAction
GreenStart the vehicle
YellowSlow down
RedStop the vehicle

Signal: 
signal = input("Enter Traffic Signal: ")
if signal.lower() == "green":
    print("Signal : GREEN")
    print("Action : Start the vehicle.")
    print("Drive carefully.")
elif signal.lower() == "yellow":
    print("Signal : YELLOW")
    print("Action : Slow down.")
    print("Be ready to stop.")
else:
    print("Signal : RED")
    print("Action : Stop the vehicle.")
    print("Wait until the signal turns Green.")
