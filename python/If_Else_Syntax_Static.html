IF - ELSE STATEMENT IN PYTHON

Keywords

if : Starts the decision making statement.

else : Executes when the condition is False.

SYNTAX
if condition:
    statement(s)

else:
    statement(s)

Explanation

Condition : Evaluates to True or False.

: Begins the indented block.

Indentation defines the block of code.

EXAMPLE
age = 20

if age >= 18:
    print("Eligible to Vote")
else:
    print("Not Eligible to Vote")
Note: Indentation is mandatory in Python. It defines the block of code under if and else.
