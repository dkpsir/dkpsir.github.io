1. Basic Theory of Decision Making

In a Python program, decision making means selecting an action depending on whether a condition is true or false.

Input
→
Condition
→
Decision
→
Action

For example, a program may check whether a student has passed, whether a number is positive, or whether a person is eligible to vote.

Basic idea:
Condition → If condition is True, execute the required statements.

5. if Statement

General Syntax
if condition:
    statement
if

Python keyword used to begin a conditional statement.

condition

Expression that produces True or False.

:

Colon indicates the beginning of the indented block.

Example

age = 20

if age >= 18:
    print("Eligible to vote")

Output: Eligible to vote

6. Indentation in Python

Python uses indentation to identify the statements belonging to a conditional block. Statements inside the if block must be indented consistently.

Correct

age = 20

if age >= 18:
    print("Eligible")

Incorrect

age = 20

if age >= 18:
print("Eligible")

7. if - else Statement

General Syntax
if condition:
    statement 1
else:
    statement 2

The if block executes when the condition is True. If the condition is False, the else block executes.

Example

number = 7

if number % 2 == 0:
    print("Even")
else:
    print("Odd")

Output: Odd

8. if - elif - else Statement

General Syntax
if condition 1:
    statement 1
elif condition 2:
    statement 2
else:
    statement 3
Python checks the conditions from top to bottom. Once a True condition is found, its block is executed and the remaining conditions are skipped.

Example – Grade

marks = 76

if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
elif marks >= 60:
    print("C")
else:
    print("D")

Output: B

9. Nested if Statement

A nested if means placing one if statement inside another if statement.

if condition 1:
    if condition 2:
        statement

Example

age = 20
has_id = True

if age >= 18:
    if has_id:
        print("Entry permitted")

Output: Entry permitted

11. Conditional Expression / Ternary Operator

General Syntax
value1 if condition else value2

Example

age = 20

result = "Adult" if age >= 18 else "Minor"

print(result)

Output: Adult

Use a conditional expression for a simple two-way decision. For complex decisions, the normal if - elif - else structure is usually clearer.

14. Important Points to Remember

  • Decision making allows a program to select an action based on a condition.
  • A condition produces either True or False.
  • Use comparison operators to compare values.
  • Use and, or and not to combine or modify conditions.
  • if is used for one-way decision making.
  • if - else is used for two-way decision making.
  • if - elif - else is used for multiple alternatives.
  • Python uses indentation to define a block of statements.
  • Use == for comparison, not =.
  • The range() stop value is excluded.
  • Use nested if only when a decision genuinely depends on another decision.
