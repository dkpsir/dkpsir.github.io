Stress and Strain Calculator Using Functions

Objective

  • Illustrate modular programming using user-defined functions.
  • Compute stress, longitudinal strain and lateral strain.
  • Separate computation and display using a dedicated display() function.

Equations Used

  • A = πd²/4
  • A = b×t
  • σ=P/A
  • ε=PL/(AE)
  • εlat=Δd/d

Complete Program (Organized by Functions)

display()

def display(area, stress_value, long_strain, lat_strain):
    print("\n----- RESULTS -----")
    print("Area                :", area)
    print("Stress              :", stress_value)
    print("Longitudinal Strain :", long_strain)
    print("Lateral Strain      :", lat_strain)

def longitudinal_strain(load, length, area, young_modulus):
    return (load*length)/(area*young_modulus)
